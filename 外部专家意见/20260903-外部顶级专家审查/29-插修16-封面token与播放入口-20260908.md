## 施工顺序：R1 → R2 → R3

### R1【#1】管理端封面预览 token 修复

**修法**：`activityCoverUrl` 拼 query token（管理端 JWT 取自 localStorage——与 request.ts 同源读取）：
```typescript
export function activityCoverUrl(id: number): string {
  const token = localStorage.getItem("admin_token"); // 与 request.ts 的 key 同源——实读确认 key 名
  return `/api/admin/activities/${id}/cover-media${token ? `?token=${encodeURIComponent(token)}` : ""}`;
}
```
上传后刷新预览的 `?t=${Date.now()}` 与 token 参数共存（`&t=`）——**改后实测**：上传 → 预览立即显示。

**注意**：cover-media 端点已支持 query token 双通道（T45 注释声明），纯前端修。
