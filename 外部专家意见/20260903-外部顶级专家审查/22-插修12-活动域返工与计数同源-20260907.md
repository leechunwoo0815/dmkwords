## S4【#5】refunded 后无法再报名（后端+前端双层修）

**根因双层**：
- 后端：`_my_enrollment_map` 不过滤状态——refunded/cancelled 终态记录也进 map → 详情接口 my_enrollment 永远非空
- 前端：wxml `wx:if={{!activity.my_enrollment}}` 才显示"立即报名"——my_enrollment 非空（哪怕是已退款的死记录）→ 报名入口消失

**修法**：
1. 后端 `_my_enrollment_map`：每活动取**最新一条**，且**仅当状态属 ACTIVE_STATUSES**（pending_payment/enrolled/checked_in/refund_pending）才入 map——终态记录（refunded/cancelled）不占报名入口位（历史在"我的活动"列表仍全量可见，别处不改）
2. 前端 activity-detail wxml/`js`：防御性对齐——`my_enrollment.status` 非活跃态时按"未报名"渲染入口（后端修对后理论上不会走到，双保险）
3. enroll 后端判定不动（ACTIVE_STATUSES 已正确：refunded 不在其中=允许重报）

**红测试**：报名→付款→退款全流程走完（enrollment=refunded）→ detail 接口 my_enrollment=None（当前返回 refunded 记录 = RED）→ 再 enroll → 200 成功（当前前端入口消失；后端本就允许，加 API 层断言锁定）。

**验证**：C 级 + 真机目视（退款过的活动详情 → 显示"立即报名" → 报名成功）。
