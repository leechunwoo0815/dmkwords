## B1【bug+需求补全·最大卡】读完即时解锁测验 + 引导弹窗

**位置**：

- miniapp/pages/reading-pkg/reader/reader.js onEnded（\~L133-148）

- miniapp/pages/reading-pkg/book-detail/book-detail.js（无 onShow——只有 onLoad L27）

**现象（两层叠加）**：

1. book-detail 只在 **onLoad** 拉进度——从 reader 返回走 onShow 不刷新，显示旧 finished=0（"要退出重进 2 次才显示"= 只有新 onLoad 才拉到新值）
2. reader 的 onEnded 上报后**不消费 finished 态**——"已读完，是否去测验"弹窗功能压根不存在

**修法**：

1. **reader.js onEnded**：report 成功后 loadProgress()（已有），随后检查：

```javascript
.then(() => this.loadProgress())
// B1：完播即时引导测验（just_finished 只在跃迁那次上报返回，
// 心跳跨阈值时 finished 已置 1——以 loadProgress 后的 finished 态为准）
.then(() => {
  const p = this.data.progress
  if (p && p.finished && !this._finishPrompted) {
    this._finishPrompted = true
    wx.showModal({
      title: '已读完！',
      content: '是否立即测验？每本书共 3 次测验机会',
      confirmText: '去测验',
      success: (r) => {
        if (r.confirm) wx.navigateTo({
          url: `/pages/reading-pkg/quiz/quiz?book_id=${this.data.bookId}&book_title=${encodeURIComponent(this.data.book.title || '')}`
        })
      }
    })
  }
})
```

`_finishPrompted` 页面级防重复（同一次会话只弹一次；onLoad 重置）。
注意：reader 页自身有 progress 数据吗——若 reader data 无 progress 字段，loadProgress 是 book-detail 的方法；reader 侧改为消费 report 响应体（后端返回 `just_finished`）+ onEnded 后兜底再查一次 progress（api.getProgress）。**以 dev 实读两页数据流为准择一实现，简报说明选择**。
2\. **book-detail.js 加 onShow**：

```javascript
onShow() {
  // B1：从 reader/quiz 返回即刷新三态（onLoad 只在首次进入触发）
  if (this._inited) { this.loadProgress(); this.checkFavorite(); this.loadBorrowState(); }
}
```

onLoad 末尾置 `this._inited = true`（防首次进入双拉）。

**验证**：代码 + 真机目视（读完 → 弹窗 → 去测验 → 返回详情显示已读完/测验已解锁，全程不退出页面）。
