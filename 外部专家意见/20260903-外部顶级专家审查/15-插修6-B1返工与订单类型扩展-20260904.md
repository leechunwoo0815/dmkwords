## R1【返工·bug】测验跳转缺 child\_id → 422

**根因（实锤）**：reader.js onEnded 跳转 URL 只带 book\_id/book\_title；quiz.js:29 `Number(options.child_id)` = NaN → `GET /api/miniapp/quiz/{id}?child_id=NaN` → FastAPI 422 "unable to parse string as an integer"。
（任务卡示例 URL 漏参系专家之锅，已认账；本卡顺带全库 sweep 同族）

**修法**：reader.js 跳转 URL 补参：

```javascript
url: `/pages/reading-pkg/quiz/quiz?book_id=${this.data.bookId}` +
     `&book_title=${encodeURIComponent(this.data.book.title || '')}` +
     `&child_id=${this.data.childId}&child_name=${encodeURIComponent(this.data.childName || '')}`
```

**同族 sweep**：`rg -n "navigateTo" miniapp/pages/ | rg "quiz"` 核对全库跳 quiz 的入口（book-detail 原入口 L137 带参是否完整）+ `rg -n "Number\(options\." miniapp/pages/` 找"解析参数但入口可能不带"的同族点，命中清单进简报。

**验证**：代码 + 真机（读完 → 弹窗 → 去测验 → 正常出题）。

## R2【返工·语义升级】弹窗条件改测验状态门控

**用户语义（裁定原文）**："测验没通过、次数小于 3 次，读完就应该弹提示引导"——弹不弹看**测验状态**，不看会话。

**修法**：reader.js onEnded 弹窗段重构：

```javascript
.then(() => this.loadProgress())
.then(async () => {
  if (!this.data.finished || this._finishPrompted) return
  // R2：测验状态门控（用户裁定 2026-09-04）——未通过且有机会才引导；
  // passed 后不再弹（孩子已过关）；attempts 用尽不弹（无意义）
  try {
    const q = await api.getQuiz(this.data.bookId, this.data.childId)
    if (q.status !== 'available') return  // passed / failed(次数尽) / locked 不弹
    this._finishPrompted = true  // 会话内防重复轰炸（跨会话 onLoad 重置，可再弹）
    wx.showModal({ title: '已读完！',
      content: '是否立即测验？每本书共 3 次测验机会（剩余 ' + q.attempts_left + ' 次）',
      confirmText: '去测验',
      success: (r) => { if (r.confirm) wx.navigateTo({ /* R1 补参后的 URL */ }) }
    })
  } catch (e) { /* getQuiz 失败不阻塞阅读体验 */ }
})
```

注意：getQuiz 的 status 语义以实际后端为准（available/passed/failed/locked 四态，读 quiz.js L18 注释），failed 若表示"次数尽"则不弹正确；若 failed 仅表示"上次没过但还有次数"，则条件应为 `q.status === 'available' || (q.status === 'failed' && q.attempts_left > 0)`——**dev 实读后端判定后择一，简报声明**。

**验证**：真机三场景：①未读过 → 读完 → 弹（回归）；②已读完未通过 → 重进再读完 → **弹**（本次返工目标）；③测验已通过 → 读完 → 不弹。
