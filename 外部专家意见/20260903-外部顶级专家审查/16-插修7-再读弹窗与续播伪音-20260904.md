### R5【核心修复】reader onPlay 无条件重设会话起点——"再读完不弹"根因

**位置**：miniapp/pages/reading-pkg/reader/reader.js onPlay（\~L108-111）

**根因链（实测推演）**：

1. 第一次读完：onEnded 尾部 `this._sessionStart = endPos`（=音频总长）
2. 再点播放：微信 ended 后再 play **从头播**（currentTime=0），但现守卫
   `if (this._sessionStart === null)`——旧值非 null **不重置**
3. 从头播完：onEnded 判 `endPos > _sessionStart` → `300 > 300` = false
   → **上报 + loadProgress + 测验引导弹窗链整体跳过**

**修法**（删 null 守卫，每次 play 以当前位置为新会话起点）：

```javascript
audio.onPlay(() => {
  // R5（插修7）：无条件重设——ended 后再 play 微信从头播（currentTime=0），
  // 若沿用 onEnded 尾部推进的 _sessionStart=旧endPos，则再播完
  // endPos>sessionStart 恒 false，上报+测验引导弹窗整体跳过（再读不弹根因）
  this._sessionStart = Math.floor(audio.currentTime || 0)
  this.setData({ playing: true })
})
```

**语义安全四推演（简报必须逐条复述确认）**：

- 首次播放：currentTime=0 → 起点 0（行为不变）

- ended 后再 play：currentTime=0 → 起点 0 → 播完 300>0 ✓ 上报+弹窗（**本卡目标**）

- 暂停后继续：onPause 的 \_reportNow 已把 \_sessionStart 推进到暂停位置；resume 的
  onPlay 重设为同一位置 → 区间连续（行为不变）

- seek 后播放：onSeeked 已重设，onPlay 再设同值（幂等无害）

### R6【体验修复】已读完的书不续播——"一闪而过伪音"根因

**位置**：reader.js `_applyResume()`（\~L97-103）

**根因**：`lastPosition > 0` 即 seek——已读完的书 last\_position≈99%，进 reader 点播放
从 297 播到 300（约 3 秒伪音），还要再点一次才从头。

**修法**（续播语义只属于未读完的书）：

```javascript
_applyResume() {
  // R6（插修7）：已读完的书不续播——last_position≈99% 时点播放"一闪而过伪音"，
  // 需二次点击才从头。"再次阅读"应从头开始；续播仅服务未读完的书
  const { lastPosition, finished } = this.data
  if (lastPosition > 0 && !finished && this._audio && !this._resumeApplied) {
    this._audio.seek(lastPosition)
    this._resumeApplied = true
  }
}
```

**时序安全**：loadProgress 先 setData(finished/lastPosition) 再调 \_applyResume；
onCanplay 早到时 finished/lastPosition 均为初始值 false/0 不会误 seek；
`_resumeApplied` 幂等标志保留。
