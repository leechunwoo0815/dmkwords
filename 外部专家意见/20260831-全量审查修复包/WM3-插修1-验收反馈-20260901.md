## WM3-A1 订单 tab 计数懒加载守卫（WM13-F4 同族漏网）

- **验收可见性**：必撞。默认 tab（孩子档案）下订单 tab 标题显示「订单（0 · 待确认 0）」，点进订单 tab 才变正确（实测 9 · 待确认 2）。
- **证据**：`admin-web/src/pages/MemberManage.tsx:297-302`
  ```text
  useEffect(() => {
    if (tab !== "orders") return;      // ← 守卫：默认 tab 下计数永远不拉
    apiOrderCounts().then(...)
  }, [tab, orderTotal]);
  ```
- **根因**：计数请求被 tab 守卫拦截，页面挂载时不发。与 WM13-F4（通知中心 tab 计数）完全同族——P0 批只修了通知中心一处，未做全站 sweep（教训已入 E-20260901-02）。
- **修复**：删除 `if (tab !== "orders") return;` 一行，页面挂载即拉计数；deps 保持 `[tab, orderTotal]`（订单增删后 orderTotal 变化自动刷新，无害）。tab 标题 fallback `orderCounts.total || orderTotal` 保留。
- **同族 sweep（E-20260901-02 新规，必做）**：`rg -n "tab !== " admin-web/src` 排查全站同款守卫模式，在交付简报附同族清单（每处标注：修/不修+理由）。
- **验证**：`pnpm exec tsc --noEmit` + 浏览器目视（登录直进会员管理，不点订单 tab，标题即显正确计数）。
- **事实/推断**：事实（代码+用户实测双重实锤）。

## WM3-A2 订单"创建时间"列永远空白（字段名错配）

- **验收可见性**：必撞。订单列表创建时间列全部空白。
- **证据**：
  - 前端 `MemberManage.tsx:438`：`{ title: "创建时间", dataIndex: "created_at", key: "created_at", ... }`
  - 后端 `backend/domain/identity/schemas.py:79`：`created_at: datetime = Field(alias="create_time")`——FastAPI 默认 by_alias 序列化，JSON 实际键为 `create_time`
  - 铁证：`admin-web/src/api/schema.d.ts:3196` OrderResponse 只有 `create_time: string`，**根本没有 created_at 字段**——前端 dataIndex 读的是不存在的键
- **根因**：前端凭记忆写了 `created_at`，未对照 schema.d.ts（宪法五-3 禁手写类型的同族病：这次类型没手写，但字段名是拍的）。
- **修复**：`dataIndex: "created_at"` → `"create_time"`。**注意**：`key: "created_at"` 保留不动——排序走 columnKey 映射 `created_at_asc/desc`，后端白名单（`service.py:596-600` order_map）就是这对键，动了排序就断。
- **验证**：tsc + 浏览器目视创建时间列出值；点排序图标仍生效。
- **事实/推断**：事实。

## WM3-B1 家长/孩子 编辑+删除（订单守卫）【用户拍板：字段全开】

- **验收可见性**：可复核。用户验收反馈"打错字提交了改不了删不了，很尴尬"。
- **用户口径（原话）**："强烈建议新增家长信息和孩子信息的修改编辑和删除功能……但前提是还没创建用户订单，创建订单以后禁止删除和修改。"
- **范围**：
  - 家长编辑：姓名、手机号（手机号唯一性校验，与新建同规；**手机号是小程序登录标识**，修改时弹窗提示"手机号即登录账号，修改后家长需用新号登录"）
  - 孩子编辑：姓名、英文名、性别、生日、年级
  - 删除：软删（`is_deleted=1`，项目既有模式）
  - **守卫（双保险）**：
    - 孩子：该孩子存在任何未删订单（`Order.child_id == X` 且 `is_deleted=0`，任意状态含 cancelled）→ 禁改禁删
    - 家长：名下任一孩子存在订单 → 该家长禁改禁删
    - API 层返回 409 + 明确中文 message（"已创建订单，禁止修改/删除"）；UI 层按钮禁用 + tooltip 说明原因
- **入口 UI**：孩子档案行操作列加"编辑/删除"；家长侧**新增"家长（N）"tab**（与孩子档案/订单并列；列表列：姓名/手机号/名下孩子数/创建时间 + 编辑/删除），交互对齐 WM2 基线（docs/07 第十二章）。
- **端点**：PATCH/DELETE `/api/admin/members/parents/{id}` 与 `/api/admin/members/children/{id}`（路由风格对齐 identity/router.py 既有命名）。
- **红测试（先红后绿）**：
  1. 编辑无订单孩子 → 200 且字段落库
  2. 编辑有订单孩子 → 409
  3. 删除有订单家长 → 409
  4. 删除无订单家长 → 列表消失（软删）
  5. 家长手机号改成已存在号 → 422
- **BDD**：features/ 对应 WM3 feature 文件补场景（编辑成功/订单守卫拒绝/手机号唯一）。
- **docs**：docs/03-Feature全量清单.md 登记 + PRD 增量（含变更记录，勿动已定稿内容）。
- **gate**：B 级（相关 pytest）。无迁移。
- **事实/推断**：需求为用户拍板；守卫口径按用户原话执行（注：若复验时用户想放宽为"有订单仅禁删、名字仍可改"，单独说一声即可调整）。
