### WM12-P3 ✅前置：token-in-query 换短时效媒体 token（HIGH-14 安全债主卡）

- **证据**【事实】（全量清单）：6 个媒体端点用 query 传 JWT——
  - parent token **30 天有效期**：`/api/miniapp/covers/{id}`、`/api/miniapp/books/{id}/audio`、
    `/observation-images/{path}`（reading/miniapp_router.py:253-318）、
    `/api/miniapp/reports/{kind}/image`（growth/miniapp_router.py:101-127）
  - admin token 8h：`/api/admin/books/{id}/cover-media`、`/audio-media`
    （catalog/router.py:88-111）
  - 前端拼接点：`miniapp/utils/media.js:13`、`api.js:72,144`、
    `pages/reading-pkg/reader/reader.js:109`、admin-web `api/catalog.ts:205-211`
- **问题**：query token 进 uvicorn access log（.dev-logs/backend.log 无轮转）；
  parent token 泄露 = 30 天家长全身份（可上报进度/建预约/申请退款退会转让），
  且 **parent token 无撤销机制**（payload 仅 sub/type/exp——对照 admin 有 gen）。
- **修复方案**（低成本三步）：

```text
# ① 签发独立的短时效媒体 token（10 分钟）：
def create_media_token(parent_id: int) -> str:
    payload = {"sub": str(parent_id), "type": "media", "exp": now + 10min}
    return jwt.encode(payload, SECRET_KEY, "HS256")

# ② 媒体端点鉴权改 _media_from_token（校验 type=="media" + exp）
# ③ 业务 API 鉴权处（get_current_parent/_parent_from_token）加 type 白名单：
#    type 必须是 "parent"——媒体 token 调业务 API 一律 401
```

  media token 泄露仅 10 分钟内可拉媒体，不能做任何业务操作。admin 媒体端点同款
  （P0-F3 修复校验 type 后收紧 exp）。
  **同时补 parent token 撤销**：Parent 模型加 token_generation 字段（迁移），
  _parent_from_token 校验（对齐 admin gen 机制）。
- **测试要求**：媒体 token 调业务 API 断言 401；媒体 token 过期断言 401；
  改密/撤销后 parent token 断言 401
- **验证等级**：C 级（鉴权体系 + 迁移 + miniapp 三端联动）
- **标注**：【事实】（清单亲验）；泄露后果【推断】
