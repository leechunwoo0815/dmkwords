## 三、用户隐私保护指引（照抄）

**收集的信息**：
- 勾选：**手机号**（用途：登录、会员建档、到店核验）
- 勾选/填写「其他信息」：孩子姓名/昵称、英文名、**从系统内置头像中选择的头像**、年龄、年级、阅读记录
  （来源：家长或馆员在门店录入；用途：阅读服务、阅读榜与适读内容）
- **不要勾选**：位置、通讯录、相册、摄像头、麦克风、剪贴板、微信运动、微信昵称/头像、设备信息
  （小程序代码里没有这些 API 调用）

**保存期限**：会员服务期间及退会后按馆方规则保留阅读记录；家长可要求删除。

**与小程序内《隐私政策》一致**：版本 v2，更新日期 2026-11-06（`miniapp/pages/agreement/privacy-policy/privacy-policy.wxml`）。

## 四、提交审核备注（照抄）

> 本小程序为**线下实体书店的会员内部配套工具**，仅服务本店已建档会员（目前数十人），
> **不对外开放注册、不面向公众提供内容服务、不销售任何虚拟商品或课程**。
> 主要功能：到店图书借阅与预约、线下活动报名、借阅/押金记录查询、会员阅读记录。
> **当前未开通线上支付**，会员服务费、活动费、图书押金均在门店线下缴纳。
> 随书音频由本店线下外教录制，仅本店会员可听，是纸质书借阅的配套服务，不单独售卖、不提供下载。
> 阅读圈为**馆内荣誉墙**：卡片由系统生成，无评论、无用户上传图片或文字。
> 测试账号：手机号 `13xxxxxxxxx`（已在门店建档；提审前替换为真实测试号）。

## 五、提审前真机自测（S430–S435）

`docs/04` §九十三 S430–S435。最低限度走一遍：

1. 未登录打开 → 登录页有「仅面向本店线下会员」提示 + 协议链接可点开；
2. 勾选协议 → 微信一键登录 → 手机号快速验证 → 进入首页；
3. 触发 `getPhoneNumber` 时应出现**隐私授权弹窗**（同意/拒绝），拒绝后不再继续；
4. 图书 → 详情 → 预约/借阅入口；活动 → 报名；我的 → 阅读记录；
5. 会员服务页：**没有任何"在线支付/去支付/立即支付"按钮**，只有"到店缴纳"；
6. 我的 → 隐私政策 → 内容为 v2（手机号/孩子信息/阅读数据，无"上传图片"）。
