## §禁做清单 v183

1. **不要连发推送**：代码推送后全量门禁在跑时再推，会被 `ci-<ref>` 并发组取消（已踩 5 次）。**文档推送已拆到 `docs.yml` 独立组**（B2-4 已治），但**代码推送之间**仍互相取消 —— 批次末一次推。
2. **不要在生产机上用 Python 改配置文件写中文注释**：生产 python3.6 默认 ascii → `write_text` 会**先把文件截断再抛错**。昨晚因此把 `/etc/my.cnf` 和 nginx vhost 各截断成 0 字节一次（nginx 那次站点 2 分钟不可用，且 **`nginx -t` 对"server 块全丢"仍报语法 OK**）。规矩：**配置一律 ASCII 注释 + 临时文件 `os.replace` 原子写 + 写前断言（段数/长度）+ 写后自检**。
3. **`nginx -t` 只证明语法，不证明语义**；改完必须再验 `https_root==200`。
4. **MySQL 8.0 没有 `Innodb_deadlocks` 计数器**；死锁只看 error log（现已开 `innodb_print_all_deadlocks`）。
5. **回滚不许盲删迁移文件**：`release_rollback.sh` 只在"快照版本 == DB 版本"时成对回退 `alembic/`；其余情况保留文件并打印 downgrade 命令。
6. **不要加 worker**（`WEB_CONCURRENCY>1` / `--workers>1` / `-wN` 都会被 `main.py` 拒启）。
7. **`/health` 恒 200（存活），`/ready` 才是就绪**；nginx 目前**没有反代 `/ready`**（复审指出：外部探针打不到，只对机内有用）——要外部探测得加 nginx location。
