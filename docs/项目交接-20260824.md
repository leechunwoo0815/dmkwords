## §本轮（v184）已完成：B1-1 + B1-2（提交 `02c05c7`）

**问题（双审查 P1-1 / P1-2）**
- **B1-1**：`assert_order_refund_executable` 是普通读，且口径刻意**不含 `failed`**（含了会把"失败重试"这条合法路径拦死）。
  于是同一订单两笔 `failed` 退款单**同时**重试时互相看不见对方（REPEATABLE READ 快照 + 对方未提交），各自算 0+本单金额 ≤ 订单金额 → **两笔都放行**。
  **修前探针实测：订单 500 → `refunded 500 + processing 500 = 1000`**（真的出款两倍）。
- **B1-2**：会员费退款申请（R-309 联动建退会单）只锁订单行，"已有进行中退会"判重是普通读，与家长侧
  `WithdrawalService.apply`（锁 Child）互相看不见对方的未提交行 → 同一孩子可挂**两张活跃退会单**（押金退两遍）；
  聚合推进 `_advance_withdrawal` 也是普通读 + 盲写。

**修法：一条全局锁序 + 一个条件唯一约束**
1. 新增 **`backend/domain/identity/lock_order.py`**：锁序单一事实源 **`Child → Order → RefundRequest → Withdrawal → Deposit`**
   + 原语 `lock_child/lock_order/lock_refund_request/lock_withdrawal/lock_refund_head`（均链 `populate_existing`）。
2. `RefundService.execute` **两段式**：先无锁定位读拿键 → 按锁序加锁 → 锁定读刷新。**订单行锁 = 同一订单退款的串行化点**。
3. 两道累计闸统计改**锁定读**（逐行 `FOR UPDATE` 后 Python 求和），锁内读到必是最新已提交状态。
4. `RefundService.apply` **先锁 Child**；`RefundService.review` 由 `RefundRequest → Order` 逆序改正；`WithdrawalService.review`/`cancel` 由 `Withdrawal → Child` 逆序改正；押金行改锁定读写。
5. `refund_online` 三个"只锁退款单"入口（网关 Phase 3 / 查单 / 回调落终态）统一先锁 Child（`_lock_child_then_refund`）。
6. 聚合推进锁退会行；两个推进函数按域搬到 `wm10_withdrawal_service`（`advance_withdrawal` / `settle_withdrawal_on_terminal`），
   `wm10_service.py` 826 → **739 行**（god-file 800 红线）。
7. 迁移 **`e7c4d1a9b3f6`**：生成列 `active_uniq_key`（活跃三态 → `child_id`，其余 NULL）+ 唯一索引
   `uq_withdrawal_active_child`；建索引前**存量去重 + 再复核**；表达式与模型 `ACTIVE_WITHDRAWAL_KEY_SQL`
   逐字一致并由用例从 `information_schema` 回读比对（照活动报名 P2-9 的规矩）。**退款单不加同类约束**（部分退款/失败重试合法）。

## §禁做清单 v184

1. **不要连发代码推送**：代码推送后全量门禁在跑时再推，会被 `ci-<ref>` 并发组取消（已踩 5 次）。
   文档推送已拆到 `docs.yml` 独立组，且 `ci.yml` 的 `paths` 排除文档面（`docs/api/**` 除外）→ 纯文档推送不会再掐断代码 CI。
2. **跑 pytest / gate 之前必须 `bash scripts/dev.sh stop`**：pytest 与 dev 后端**共库**，后端持表锁会让 TRUNCATE 挂起/报错，
   表现是**一片假红**（本日实测：门禁尾部自动 `dev.sh restart` 恢复现场后紧接着再跑一次门禁 → 步骤 [2] 冒出 20+ 个 F）。
   **规矩**：每次开跑前先 stop；顺带核查 `lsof -ti tcp:8443`（本日发现一个跑了 14 小时的孤儿 uvicorn 占着 8443 且握着调度器锁）。
3. **不要在生产机上用 Python 改配置文件写中文注释**：生产 python3.6 默认 ascii → `write_text` 会**先截断再抛错**。
   规矩：配置一律 ASCII 注释 + 临时文件 `os.replace` 原子写 + 写前断言（段数/长度）+ 写后自检。
4. **`nginx -t` 只证明语法**；改完必须再验 `https_root==200`。
5. **MySQL 8.0 没有 `Innodb_deadlocks` 计数器**；死锁只看 error log（已开 `innodb_print_all_deadlocks`）。
6. **回滚不许盲删迁移文件**：`release_rollback.sh` 只在"快照版本 == DB 版本"时成对回退 `alembic/`。
7. **不要加 worker**（`WEB_CONCURRENCY>1` / `--workers>1` / `-wN` 一律拒启）。
