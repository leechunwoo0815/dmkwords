2. **`docs/33` §五 遗留 1 的旧定位已被 166 批修正**：原写"绘本风图书页 90px"是错位（图书页 19px，85px 在系统配置页）；166 批已把修前基线表与修后 0 溢出写回 `docs/33`，别再照旧结论去给图书页单独调列宽。
3. **门禁 [9] 只对 `??` untracked 判红**（本卡已亲验 `scripts/gate.sh:241`：`grep '^??'`），**已 `git add` 的 `A ` 不判红**。但仓库纪律仍要求跑门禁前工作区干净，所以新文件先 add。
4. **不要重复跑全量门禁来"验证文档"**：全量约 **45–60 分钟**（pytest 44:28 + BDD 10 + 检查器）。纯文档按 D 级不跑。
5. **不要往 `cssVars()` 里加没有消费点的变量**：CSS 变量只注入 CSS 实际消费的；antd/JS 消费的令牌走 `buildAntdTheme`/`getTheme`。`scripts/check_theme_tokens.py` 会对"零消费"判红（唯一放行是 `--chart-1..6` 色板契约）。
