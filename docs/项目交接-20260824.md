## 3. 关键踩坑记录

1. **CI 首败**：F1-F4 推送后 CI 失败，根因不是 tsc，而是 `ruff format --check .` 发现 2 个 Python 测试文件未格式化。修复后 CI 绿。
2. **tsc 诊断插曲**：为定位 CI 失败临时改 `scripts/gate.sh` 加 tsc 诊断输出，最终已恢复原状。
3. **schema.d.ts 必须提交**：新增 `BatchDeleteRequest` 等 OpenAPI schema 后，必须重新生成 `admin-web/src/api/schema.d.ts` 并提交，否则 CI tsc 失败。
4. **绘本字体 CDN**：ZCOOL KuaiLe 通过 fontsource CDN 加载；如 CDN 不可用，管理端标题字体会回退到系统字体。
5. **`transform` 动画不能加在 antd Modal 上**：会破坏 pointer-events 层级，导致关闭/取消/保存按钮全失效。
6. **`:nth-child()` 不能用于权限过滤后的菜单**：用户权限不同导致可见菜单数不同，`:nth-child()` 会错位，必须按业务 key 传色。
