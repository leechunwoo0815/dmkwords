### 2.3 ✅ 已收尾：bug#4 的收尾——"最后一段进度丢失"（继任第一件事）

**现象**：4 秒音频播完，服务端 intervals 只记到 [0,3]，coverage 75%，**finished 永远不触发**
（95% 判定差最后 1 秒）。

**根因**：`reader.js` 的 `_reportNow()` 取 `position = Math.floor(audio.currentTime)`——
**onEnded 触发时 currentTime 已被基础库归零** → `position(0) <= sessionStart` → 直接 return
跳过上报。onEnded 里虽然调了 `_reportNow()`，但 position 恒为 0，等于没调。

**已落盘的修复**（`miniapp/pages/reading-pkg/reader/reader.js` 的 onEnded 回调）：
```js
audio.onEnded(() => {
  // 播放结束 currentTime 已归零，_reportNow 会因 position<=sessionStart 跳过——用总时长兜底
  const endPos = Math.floor(audio.duration || this.data.duration || 0)
  if (this._sessionStart !== null && endPos > this._sessionStart) {
    api.reportProgress(this.data.childId, this.data.bookId, endPos, this._sessionStart).catch(() => {})
    this._sessionStart = endPos
    this._pendingSec = 0
  }
  this.setData({ playing: false })
})
```
语法已 node --check 通过。

**验证结果（2026-08-30 深夜）**：模拟器端到端实测 book 2（5s 音频，半听 2/5 续播）→
播放至 onEnded → 查库 `reading_progress` coverage=5/5、**finished=1**、intervals=[0,5]、
last_position=5 ✓。截图 v6-onended-before/after.jpg。原"模拟器时间不推进"边界声明已推翻
（差异在触发路径：UI 点击依赖 onCanplay 起播，evaluate 直调 onTogglePlay 可推进时间）。
报告 §二B + 错误记忆库 20260830 已更新。
**遗留观察（E-20260830-11，已修复 2026-08-30 晚）**：播完 UI 显示"已覆盖 60%"而非 100%
（竞态：loadProgress 与最终上报并行拿到旧值）。已修：onEnded 里
`reportProgress(...).then(() => loadProgress())` 上报落库后再刷新。实测 UI 显示
"已覆盖 100% + 已读完"、滑块到头（v6-onended-ui100.jpg）。
**另发现 E-20260830-12**：重置进度时 intervals 误写一维 `[0,2]` 触发 report_progress 500

## 4. 本轮新坑（错误记忆库 20260830 待补录，防复发红线级）

1. **WXSS 中文类名卡死页面导航**：`.cat-资金` 使 navigateTo 直接 timeout（渲染错误吞掉导航
   响应）。类名一律英文，中文文案进 data。（卡了 20 分钟才定位）
2. **WXML 不支持 `.split()` 等方法调用**（C47 字符串下标同族+1）：picker 显示文本必须 js 预计算
3. **seed_dictionary 全表拉内存**：`existing = {r[0] for r in query(DictionaryWord.word).all()}`
   把 340 万行拉进 set，而 conftest **每个测试模块**都调它——词库 309 词时不暴露，
   全量导入后 pytest 卡死 23 分钟。已修（IN 查询）。**教训：大表环境下的 .all() 全表拉取**
4. **MP3 解析只覆盖 MPEG1**：lame 低采样率输出 MPEG2 Layer III（fff3），漏解析 → 时长 0 →
   兜底值毒化完播判定。修法见 file_storage.py（三版本比特率/采样率/576 samples 表）
5. **`display:none` + `wx:if` 组合弹层不可见**：wx:if 渲染的节点永远不会有 `.show` 类。
   显隐二选一：要么 wx:if（去掉 display:none），要么 class 切换（去掉 wx:if）
6. **slider 刻度 `Math.max(100, duration)`**：短音频刻度被撑到 100，滑块看似不动；
   onCanplay 在部分基础库不触发，onTimeUpdate 里必须做时长校准兜底
7. **onEnded 时 currentTime 归零**：最后一段进度上报必须用 audio.duration 兜底（§2.3）
8. **模拟器编译缓存假象**：wxml/wxss 改动后旧页面热重载不彻底——先 simulator_refresh 再验证
9. **IDE 登录态过期**是"模拟器连不上"的第一嫌疑（MCP 报"需要重新登录"/APPID_ERROR）
10. **两个家长数据**：演示数据挂 child_id=2；自动化从登录态取 child，禁硬编码（§1）
