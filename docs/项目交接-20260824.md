## 三、口径（改行为前先读）

### A. 音频域关键口径（本批真跑锁死）
- **收听资格**（R-313 AUDIO 行）：未缴费/退会**禁**；在册听**全馆在架**（不必借过）；过期**仅手头在借**（"在手"= 在借记录存在，**还了立刻掉权**）。判定收口 `identity.guards.check_audio`，
  **预检端点 / 音频流 / 心跳上报三处同源**（禁漂移）；拒绝语义：预检 `{allowed:false,reason:unpaid|withdrawn|expired}`，流与上报 **403**。
- **完播判定**（§6.2）：只认真实播放区间，**并集** ÷ 总时长 ≥ `audio_finish_threshold_percent`(95%) 才算读完——拖动跳过不计、重复段只计一次、跨天累加合并。
- **防刷 R-151**：单次 Δ覆盖 ≤ **服务端墙钟**差 × 2.0（最大倍速）× 1.2（容差）+ **60s 宽限**（首次上报/网络抖动）；客户端声明跨度不作依据。首次心跳 `last_report_at is None → elapsed=0 → 只放行 60s`。
- **首次完播三件事**（§6.2）：记时长（`reading_minutes = max(1, 总秒//60)` = **音频原始时长**，2 倍速听完也记 30 分钟）、生成**当天**打卡、解锁测验；重复听不重复记、完播时刻不刷新。
- **打卡**（§6.3）：当天首次完播即打卡、**不看测验结果**；同书不重复；一天多本只算一天；连续按**自然日**，断一天从 1 重算、**已发积分不回收**；跨零点按**判定时刻**归属。

### B. 时刻态造数与判别器（本批新增手法，后续域照抄）
墙钟改不了，而防刷/跨天/跨零点的判据都拿时钟算 → 只能造**时刻态**：
- `_seed_progress`（造"上次心跳在昨天 23:50 / N 秒前"的进度行）· `_shift_or_seed`（首次心跳前先落基准行）· `_set_last_report`（设具体时刻）。
- **铁律：每段 Δ覆盖都必须落在容差内**，否则测出来的"拒绝"是造数造成的**假红**（红线 136）。
- **判别器思维**：只断言"打卡日期 = 今天"是**恒真**的（实现就是 `date.today()`）；跨零点场景额外造「昨天已有打卡行」——按会话起点归属会**漏发**、按判定时刻归属才会**新建**，
  两条口径在此构造下结果可观测地不同，断言才有意义。

### C. BDD 解封方法论（沿用，照抄）
1. 读 `@draft` 场景 → 写真实步骤（真 MySQL + TestClient）→ 跑绿 → 撤 `@draft`；**跑不到的保留 `@draft` 并写明原因**（本批 14 条**全部**真跑，无保留）。

4. **不可达态/时间态用 DB 直插或跑真任务构造**，步骤注释写明为什么走不到。
5. **behave 步骤表全局唯一**：同义步骤要么合并要么错开（本批 `孩子 "小红" 尚未入会` 错开 growth 域的 `未入会`）；**中文不分词**——特征文件里没空格，步骤文本加空格就 undefined。

### E. 本批踩到的坑（已记 `docs/09` 第五十七轮 §三）
1. **变异脚本改错位置 = 假变异**（新增红线 **147**）：第一次把 `merge_intervals` 的 `sorted(...)` 换成拼接，**后面那段合并循环还在**，恰好把乱序输入又合上了 → 场景照绿。改成整段替换并**先自证**（直接调 `merge_intervals(...)` 打印结果）才打到红。
2. **首段心跳只有 60s 宽限**：任何"首段就报几百秒"的构造都会被判增速异常 → 先落基准行。
3. `_play` 的拨钟必须**无行则造行**（首次上报前不存在进度行，直接 `_backdate` 会断言失败）。
4. 造数行的 `total_seconds` 必须等于书目音频时长（视图 `coverage_percent` 的分母）。
5. 2 倍速口径要写对：4 段 × 450s 内容 / 每段 225s 墙钟（写成"180s 墙钟报 450s"就是 2.5 倍速，超出 PRD D20 上限，只是被容差放过）。

## 三、口径（改行为前先读）

### A. 活动域关键口径（本批真跑锁死）
- **报名**：同活动同孩子唯一（活跃态）；`enroll` 先 `with_for_update` 锁活动行再算名额（并发不超卖）；付费活动报名即建单（`pending_payment`）**先占名额**；满员 409「名额已满（可到店咨询）」且**不做候补**（无任何排队副作用）。
- **待支付超时**：`pending_payment_timeout_hours`（默认 48h）→ 任务 `order_timeout_cancel` → 订单 cancelled + 报名联动取消 + **名额释放**。
- **签到**：按 `ticket_code` 定位报名（**不比对当前打开的活动**）；成功回执含孩子姓名 + 活动名 + 时间；失败四类见 §二 第 2 条；重扫不写审计、不改时间；已签到的券**仍可**被其它活动扫（越场券的兜底在**管理端前端**：比对回执活动名 → 提示「注意：该券不属于本场活动」）。
- **退款矩阵**：已签到不退；未开始未签到**全额**（`refundable_amount` 对活动费 = 订单全额）；距开始 < `activity_refund_cutoff_hours`(2) 关线上；活动取消 → 已付报名 `refund_pending` + 逐单退款申请；**拒审必须走活动域端点** `POST /api/admin/activity-refunds/{enrollment_id}/review`（只有它把报名翻回 `enrolled`；通用 `refund-requests/{id}/review` 只管台账）。
- **99 元（R-321）**：资格按**账号（parent）**；判据 = 不存在「已付且 `refund_status != refunded`」的 99 元单；退款处理中不恢复；`refunded` 即恢复（**「未参加」由审核员人工核对**，机器不判）。
- **图文详情（§9.4）**：纯展示字段，活动**开始后/结束后都能写**；核心字段（开始时间/报名截止/名额/费用）仍只在「PUBLISHED 且未开始」可改；配图落 `activity_detail/`，文件名 `{activity_id}_{hex}.ext`（前缀 = 归属校验）；上限 60 块 / 30 图 / 单段 1000 字 / 图注 60 字；活动已取消 → 图文锁定 422。
- **往期回顾（§9.5）**：按「开始已过 `PAST_AFTER_HOURS`(24h)」取数（**不是** `status=finished`）；排除已取消；返回仅活动字段 + `enrolled_total` / `checked_in_total`，**零孩子信息**；小程序显示「签到数优先，无签到退回报名数」。
- **详情页 vs 入场券页**：详情页**不渲染**券码/二维码（wxml+js 零引用），只给「出示签到码」入口且只在 `status===\'enrolled\'` 出现；接口 `my_enrollment` **仍下发 `ticket_code`**（家长自己的数据，同一报名视图）——这是**已记录的口径差异**，不是漏洞。

## 三、口径（改行为前先读）

### A. 活动域关键口径（本轮真跑锁死）
- **报名**：同活动同孩子唯一（活跃态）；先锁活动行再算名额（并发不超卖）；付费活动先建单占名额（`pending_payment`）。
- **待支付超时**：`pending_payment_timeout_hours`（默认 48h）→ 任务 `order_timeout_cancel` → 订单 cancelled + 报名联动取消 + **名额释放**。
- **签到**（§9.2.1）：按 `ticket_code` 定位报名；成功回执带 **孩子姓名 + 活动名 + 时间**；失败四类 = 券码不存在(404) / 已签到(409) / 未完成收款或已退款(422) / 活动已取消或结束(422)；重扫不写审计不改时间。
- **退款矩阵**（§9.3）：已签到不退；未开始未签到**全额**（活动费 `refundable_amount` = 全额）；距开始 < `activity_refund_cutoff_hours`(2) 关线上退款；活动取消 → 已付报名转 `refund_pending` + 逐单退款申请；**拒审走活动域端点**（`activity-refunds/{eid}/review`）才会把报名翻回 `enrolled`。
- **99 元**（R-321）：资格按**账号（parent）**；判据 = 无"已付且未全额退"的 99 元单；退款处理中不恢复；`refund_status=refunded` 即恢复（"未参加"由审核员核对）。
- **图文详情**（§9.4）：纯展示字段，活动**开始后/结束后都可写**；核心字段（时间/名额/费用）仍只在"未开始"可改；配图落 `activity_detail/`，文件名 = `{activity_id}_{hex}.ext`（前缀即归属校验）；上限 60 块 / 30 图 / 单段 1000 字 / 图注 60 字；取消后锁定。

- **留痕口径**：**家长侧自助动作不写管理员审计**（`audit_logs.actor_id` 语义是管理员 id），事实落在业务行
