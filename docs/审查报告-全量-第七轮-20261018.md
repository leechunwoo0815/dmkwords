## 4. 缺陷清单（8 字段）

### P1-1 押金 `refunded` 复位只挂观察期路径：走**年费**重新入会的孩子永远缴不了押金（第六轮 P1-1 结转，仍存在）

> **状态（2026-10-18 第七十五批·子批 4）：✅ 已修**（本轮报告出稿后当天修复）。会员状态唯一写口 `write_member_status` + 押金复位钩子，年费/转让两条重新入会路径都已覆盖；用例 `test_audit5_p1_batch4_20261018.py`（2 条），**变异 3/3 红**。

- **位置**：`backend/domain/identity/order_service.py:407-431`（`TYPE_OBSERVATION` 才调 `_open_membership`）；复位函数唯一调用点 `order_service.py:528`
- **触发路径**：退会/转让结算 → 押金置 `refunded` → 家长走**年费**重新入会（`POST /api/admin/orders` 类型=formal 或小程序续费）→ `_settle_paid` 走 `elif TYPE_FORMAL` 分支（仅顺延到期日）→ 复位不执行 → 四条缴款入口全拒（押金状态≠unpaid）→ 借书被 `borrow_gate` 拦，只能人工放行。
- **为什么是问题**：R-301 允许 `WITHDRAWN → FORMAL`；资金担保缺失且**静默**（无报错、无待办）。违反"押金每条终态都要有回退边"。
- **证据**：`静态`（调用链唯一性可机械判定）
  ```
  grep _open_membership  → 仅 order_service.py:408（TYPE_OBSERVATION 分支）
  grep reset_refunded_on_rejoin → billing/service.py:139 定义；order_service.py:528 唯一调用（在 _open_membership 内）
  TYPE_FORMAL 分支（:415-431）无复位调用
  ```
- **影响面**：退会后改走年费入会的家庭；频率低但一旦发生即"有效会员缴不了押金"。
- **建议修法**：复位移到 `_settle_paid` 的公共前置（任何开通/续费成功后都执行），不按订单类型分叉。
- **回归用例建议**：`membership.feature` 增"退会 → 年费重新入会 → 押金可缴"；断言 `deposit.status == unpaid` 且能创建押金订单。
- **变异建议**：删掉 `TYPE_FORMAL` 分支新增的复位调用 → 用例必须红。

### P1-2 续借后第二周期到期提醒被去重键永久吞掉（第六轮 P1-2 结转，仍存在）

> **状态（2026-10-18 第七十五批·子批 2）：✅ 已修**（本轮报告出稿后当天修复）。键带周期：`f"{days}:{due_at:%Y%m%d}"` / `f"overdue:{due_at:%Y%m%d}"`；用例 `test_audit5_p1_batch2_20261018.py`（2 条，可控时钟），**变异 2/2 红**。

- **位置**：`backend/domain/circulation/reminders.py:76-86`
- **触发路径**：到期前收到"今天到期"提醒（`ref_id=borrow_record.id`，`dedup_key="0"`）→ 馆员/家长续借 → 新到期日再次到"0 天"→ 唯一索引 `(parent_id,scene,ref_type,ref_id,dedup_key,is_deleted)` 判重 → 第二条不发。
- **为什么是问题**：续借是 PRD 明文功能，提醒是其配套；去重键无周期维度，违反"周期类场景的去重键必须带周期"。
- **证据**：`静态`
  ```

  ```
- **影响面**：所有续借过的记录（每本可续 1 次）；家长静默收不到第二周期提醒 → 逾期率上升。
- **建议修法**：`dedup_key=f"{days}:{rec.renew_used}"`。
- **回归用例建议**：`borrowing.feature`："到期提醒 → 续借 → 新到期日 0 天再提醒"断言两条通知。
- **变异建议**：改回 `str(days)` → 用例必须红。
