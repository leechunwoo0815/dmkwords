## 一、工作方式（goal 模式协议）

**一页一个 loop，直到 29 页全 PASS**：

```
① 读该页三件套（.js / .wxml / .wxss）+ 该页在 app.json 的注册信息
② 用开发者工具打开该页（见 §二 直达参数表）→ 截图首屏
③ 向下滚动（长页 3~5 段）→ 每段截图 → 直到页面最底（"到底啦"提示或最后一个元素）
④ 对照 §四 元素对齐契约 逐项判定（骨架/状态四件套/卡片/按钮/列表/浮层/长文本/合规）
⑤ 对照 §五 风格基准 判定（令牌/裸色/内联 style/组件复用）
⑥ 整改 → 重新截图复验 → 把结论写入 §八 审查结果表
```

**硬性纪律**：
- **禁止抽样**：29 页一页不能漏；**禁止"看起来没问题"**——每页必须有截图证据；
- **禁止用静态检查冒充目视结论**：小程序没有构建步骤，`node --check` 与
  `scripts/check_miniapp_bindings.py` 只能证明"语法/数据面"，**遮挡、覆盖、错位只能靠截图看出来**；
- 无法判定的（如真机与模拟器差异）→ 记为「待用户目视」并写明原因，**不许含糊通过**；
- 每改完一页，重复第 ②~⑥ 步**重新截图**（不是只改完就记 PASS）。

## 四、元素对齐契约（统一模板 = 不可协商）

### 4.1 页面骨架（每页必须齐）
1. 背景容器 `page-bg`；2. 顶部标题区（与 `navigationBarTitleText` 一致）；
3. 非 tab 页必须有返回（微信默认导航栏或页内返回）；4. 底部内容留白（`safe-bottom`）；
5. 有悬浮操作时用 `fixed-bottom-bar`，且**不得遮挡最后一条内容**（内容容器底部留白 ≥ 悬浮条高度）。

### 4.2 状态四件套（**统一复用组件，禁各页自造**）
| 场景 | 必须使用 | 现状 |
|---|---|---|
| 加载中 | `components/loading-skeleton` | ❌ 当前 **0 页**采用（各页自造 loading） |
| 空态 | `components/empty-state` | 3 页采用（books/shelf/messages/reservation 中部分） |
| 错误+重试 | `components/error-view` | 5 页采用 |
| 提交/支付中 | `components/pay-button` | ❌ 当前 **0 页**采用 |
→ 本次要求：**29 页全量对齐**到这四个组件（保留各页文案差异，形态与交互统一）。

### 4.3 卡片与文本
- 卡片一律 `.card`（app.wxss 已有）；卡片内标题、信息行、键值对**上收为公共类**：
  `.card-h3` / `.info-row` / `.info-label` / `.info-value`（当前散落各页，见 §五 证据）；
- 金额/价格文案一律来自接口或配置，**禁硬编码**（宪法 §五.4）。

### 4.4 按钮（四态 + 触控区）
- 统一用 `.btn-primary` / `.btn-outline` / `.btn-danger` / `.btn-disabled`（app.wxss 已有）；
- **禁每页自造** `.submit-btn` 等同义类（现存 4 处重复实现）；
- 触控区 ≥ **88rpx**；禁用态必须同时置灰 + 不可点（双保险）。

### 4.5 列表
分隔线（`1rpx solid var(--border)`）/ 行距统一 / 可点行必须有箭头或明确反馈 /
到底提示文案统一（`— 到底啦 —` 或同类，全站一种）/ 下拉刷新与触底加载行为一致。

### 4.6 浮层与遮挡（**用户重点投诉项**）
- 遮罩 z-index 分级：页面内容 < 浮层遮罩 < 支付/确认弹窗 < tabBar（**浮层不得压住 tabBar**）；
- 禁 `position:fixed` 不留 `safe-area-inset-bottom`；
- **禁写死高度的容器包长内容**（内容溢出即遮挡——活动页/详情页重点排查）；
- 弹窗内容长于视口时必须**内部可滚动**，不得溢出屏幕。

### 4.7 长文本与图片
单行省略或两行 clamp；图片固定宽高比 + 占位图；无图时不得塌陷（高度兜底）。

### 4.8 合规
隐私政策/服务协议两页必须存在、可达：**登录页**（同意勾选旁）与**我的页**要有入口。

## 五、统一风格基准线（令牌与禁项）+ 现状偏差证据

### 5.1 只允许用令牌
`app.wxss` 已定义 **49 个 CSS 变量**：颜色（`--bg --surface --fg --muted --border --accent* --secondary* --success* --warning* --error* --gold* --sun/sky/sakura/lavender*`）、
圆角（`--radius*`）、阴影（`--shadow-*`）、字体（`--font-display/body/mono`）。
**新增样式一律引用令牌**；确需裸值（渐变遮罩/品牌金）必须在该页 wxss 顶部注释登记原因。

### 5.2 禁项
`oklch()`、`backdrop-filter`、`!important`（除覆盖第三方）、内联 `style=` 写死尺寸/颜色（动态计算除外）、
自造按钮/空态/加载组件、每页重复定义同义类。

### 5.3 实测偏差证据（2026-09-13 静态扫描，供整改优先级）
| 维度 | 数据 |
|---|---|
| 裸色值 TOP | `circle.wxss` **44** / `book-detail` **24** / `deposit` **22** / `circle/profile` **15** / `member` **12** / `report` **11** / `reader` **7** / `activity-detail` **6** |
| 内联 style TOP | `refund-apply` **18** / `observation-report` **11** / `profile-card` **7** / `activity-detail` **6** / `achievement` **6** / `leaderboard` **5** / `checkin` **4** / `reader` **4** |
| 同义类各自实现 | `.empty-text` **8 页** / `.section-title` **10 页** / `.list-item` **10 页** / `.submit-btn` **4 页** / `.info-row|label|value` 各 2 页 |
| 组件采用 | `loading-skeleton` **0 页** / `pay-button` **0 页** |
| tabBar 自成一派 | `custom-tab-bar/index.wxss` **7 处裸色、0 个令牌** |
| 孤儿文件 | `member-pkg/` 下 **9 个扁平层 wxss**（与嵌套同名页重复）→ 应删 |

## 七、DoD 与门禁（每页整改后 + 收批前）

1. JS 改动：`node --check <file>`（小程序无构建步骤，这是唯一语法关）；
2. wxml 改动：`.venv/bin/python scripts/check_miniapp_bindings.py`（wxml 读的变量必须有 data 来源）；
3. 批量改动后：`bash scripts/gate.sh full`（9 步全绿；含 ruff/pytest/BDD/架构/契约/T27/tsc/完整性）
   → 跑完必须 `bash scripts/dev.sh restart` + 三项核验（书目 35/家长 3/孩子 11/活动 2、health ok、5173 200）；
4. 新增页面：`app.json` + `sitemap.json` 注册；`docs/15` 若引入新视觉规则需同步；
5. 文档同步：`docs/LEDGER.md` 加行 + 交接卡更新（**功能闭环必更文档**，宪法 §六 DoD 第 4 条）；
6. **不擅自 commit/push**：每批完成后报用户，等 OK。
