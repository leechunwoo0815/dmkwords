## §三 验收口径（每批共用的 Done 定义）

1. **失败态类**：停后端 → 页面出现「加载失败 + 不代表没有数据」横幅 + 重试；恢复后重试数据回来（截图/请求留证）。
2. **资金/状态机类**：正负两向用例 + 不变量 SQL（台账恒等）全绿；改判据的必须给变异（改坏→红）。
3. **门禁类**：`--self-test` + 主流程 + 变异；并证明「旧判据会放过的样本」现在会红。
4. **文档类**：`check_docs_code_alignment` 绿；历史报告只加「已冻结/已删」标注，不改结论。
5. **每批收尾**：`dev.sh stop` → 门禁（按级）→ 三核验（后端 200 / 管理端 200 / 基线 35·3·11·4 + 演示孩 10 项）→ LEDGER + 交接卡。
