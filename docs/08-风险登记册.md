# 08 风险登记册（v1.0 初版）

> 概率/影响：高/中/低。每条含预防（事前）与应对（事后）。Top 风险在顶层规划 §5 引用。

| # | 风险 | 概率 | 影响 | 预防措施 | 应对方案 |
|---|---|---|---|---|---|
| R1 | 大模型施工质量漂移（后续模型能力弱、不守规范） | 高 | 高 | 按图施工手册（模板化/零歧义）+ 全量门禁 + 四件套骨架照抄 | 门禁拦截即阻断；偏离项登记台账重新施工 |
| R2 | 需求再变（甲方签字前变动） | 中 | 高 | Gherkin 场景标注需求锚点（R-xxx）；骨架与需求解耦 | 变更 → rg 冲突检查 → 局部替换场景，不重构 |
| R3 | 音频未按时录完（上线前提） | 中 | 高 | 上线前提条款进合同；P2 后每周跟踪录制进度 | 上线范围降级预案：仅上架已录音频书目 |
| R4 | 微信资质阻塞（类目/支付商户号/订阅模板审核） | 中 | 高 | 立即启动申请（B1/B2 待办）；F11 前完成 | 通知降级站内单通道；支付先全走人工确认 |
| R5 | 假绿测试复活（旧项目核心事故源） | 中 | 高 | 反假绿门禁扫 tests+scripts+features；覆盖率门禁 | 发现即回滚该提交并记错误记忆库 |
| R6 | 服务器单点故障/磁盘打满 | 低 | 高 | 每日 mysqldump+binlog 备份；磁盘告警（音频上百 GB） | 恢复演练（P13 验收项）；音频迁 OSS 预案（ADR-004 抽象层） |
| R7 | 340 万词库导入拖慢主库 | 低 | 中 | F8 开工时导入（非上线前）；批量+独立索引；导入任务限速 | 查询走覆盖索引；必要时词库独立 schema |
