### 过程性事故（我的操作失误，非代码问题）

| 第一次门禁 1 失败：`test_scheduler_takes_over_after_holder_exits`（"外部连接没拿到命名锁"） | **跑门禁前没 `dev.sh stop`**，dev 后端调度器持锁 | 停 dev 后重跑 |

## 五、遗留与风险（如实）

1. **横向溢出（166 批已收口，2026-11-05）**：根因不是"绘本风 padding 更大"，而是 ① 全部表格 `scroll={{ x: "max-content" }}` 让长文本撑开列宽；② 部分页面列宽总和大于 1366 可用宽度；③ 操作列未固定。修法：`scroll.x:"100%"`（固定布局、表宽=容器）+ 数值列宽 + 文本列 `ellipsis` + 合并重复列（退款中心"审核备注"并入状态、"退款渠道"并入金额；会员订单"孩子/家长""金额/收款方式"合并）+ 操作列 `fixed:"right"`。**修后实测**：三主题 × 18 个路由/标签页（含会员三 tab、退款三 tab、通知家长 tab）表格内部溢出**全部 0**。未覆盖：生产超长文案（已用 `ellipsis` 兜住文本列，仍建议甲方用真实数据目视）。
2. **通知中心 / 退款中心 / 阅读圈 / 任务看板未用 `ListCard`**：它们是多标签面板结构，已统一页头与卡片描边，但卡头没有「标题 + 总数 + 批量操作」那一条。视觉可接受，严格一致性上差一档。**169 批已把样板页 `BookManage` 换用 `<ListCard>`（9 页使用组件）；四个面板页保持面板结构（结构不同，未强制）。**
3. **会员页筛选在标签内部**，未落进 `.list-card-filter` 灰色筛选带（其它 11 页在带内）。
4. **antd 预置色标签**（`<Tag color="blue">` 这类类型徽标）走 antd 自带调色板，不随主题主色变化——属状态分类色，刻意保留。
5. **Windows 实机观感仍未验证**：本地只有 macOS Chromium 截图；ClearType 下的字体渲染必须甲方目视。
6. 绘本风的手绘字体在**首次切换**时异步加载，约 1–2 帧内为系统字体（缓存后无感）。
7. **主题令牌零消费（167 批已收口，2026-11-05）**：20 个零消费 CSS 变量 → **16 个移除**（改由 antd/JS 消费：`colorLink` / `controlHeightSM/LG` / `siderWidth` / `fontFamilyCode` / `contentPadding` / `radiusXL` / `shadowModal` 等）、**2 个接线**（`--table-header-height` / `--table-row-height` 已进表格 CSS）、**2 个登记为色板契约**（`--chart-2/6`）。`buildAntdTheme` 4 处飞书蓝 rgba 改为 `withAlpha(c.primary)` 派生；154 处插画字面色收进 `theme/paint.ts` 的 `paintIllustration`，TSX 硬编码 hex **0**。新增 `scripts/check_theme_tokens.py`（S1/S2 自证）接 gate [5]：定义 **56** / 使用 **73** / 零消费 **0**（色板放行）/ 未定义 **0**。
8. **「每 60 秒自动刷新」只刷图形区（168 批已收口，2026-11-05）**：`overview` 纳入 60s 轮询（首载 loading，后台静默刷新；失败保留上一次成功数据并在横幅标明"显示的是上次数据"）；KPI/健康度/馆藏环/最近配置变更随 `overview` 一起刷新。KPI 区新增「数据更新于 HH:mm:ss」，趋势卡徽标改为「**图形数据**更新于 …」，不再暗示整块看板同时刻刷新。**170 批补**：页签隐藏时暂停轮询、回到前台立即补刷（静态实现；headless CDP 无 `Emulation.setPageVisibilityState`，未运行时复现）。
9. **KPI 比例条口径（168 批已收口，2026-11-05）**：17 块中只有 **8 块**有真实分母（在馆/总量、逾期/在借、新增/会员总数、待评估/会员、三个百分比、馆藏构成），其余 9 块不画比例条；文档从「每块都有真实比例条」改为「**有可比口径的磁贴才画比例条**」（不编造分母）。
10. **样板页绕过 `ListCard`（169 批已收口，2026-11-05）**：`BookManage` 已改用 `<ListCard>`（title / count / extra / filter / tabs），全仓 **9 页**使用组件；四个面板页保持面板结构。
11. **登录页无 h1 / 无主题入口（169 批已收口，2026-11-05）**：`/login` 加 `<h1 class="sr-only">` + 右上角主题 `Dropdown`（未登录可切三套主题）；`document.title` 由 `branding.ts` 写入；`index.html` 不再写死品牌名。

13. **前端判据加固（171 批，2026-11-05）**：`withAlpha` 抽到 `theme/color.ts`、KPI 规则抽到 `dashboardKpi.ts`，新增 **13 条纯函数单测**；`pnpm test:ui` 现 **25 passed**（Gauge 7 + 页面标题 5 + 颜色 5 + KPI 8），并已接 gate [7] / CI。
