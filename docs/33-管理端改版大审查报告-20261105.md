### 过程性事故（我的操作失误，非代码问题）

| 现象 | 根因 | 纠正 |
|---|---|---|
| 第一次门禁 1 失败：`test_scheduler_takes_over_after_holder_exits`（"外部连接没拿到命名锁"） | **跑门禁前没 `dev.sh stop`**，dev 后端调度器持锁 | 停 dev 后重跑 |
| 第二次门禁一片 F（5–10% 就失败） | **kill 门禁后 pytest 子进程残留**，仍占数据库；dev backend 也在跑 | `pkill -f pytest` / `pkill -f uvicorn` 清干净后重跑 |
| 第三次门禁仅 [9] 判红「工作区存在未入库文件」 | 新文件未 `git add`（门禁要求全仓无 untracked） | 先按逻辑分三个提交入库，再重跑 |

> 纪律沉淀：**跑全量门禁的三条前置**——① `bash scripts/dev.sh stop`；② 清残留 `pytest`/`uvicorn` 进程；③ `git status` 必须干净（新文件先 `git add`）。

## 五、遗留与风险（如实）

1. **绘本风 1366 下图书页仍有 90px 横向滚动**：该皮肤卡片/表格 padding 更大（曹操 20px、2px 描边），列宽按企业风调的。企业风是 0。若要绘本风也 0，需要单独一套列宽或让该皮肤密度更紧凑——**未做**。
2. **通知中心 / 退款中心 / 阅读圈 / 任务看板未用 `ListCard`**：它们是多标签面板结构，已统一页头与卡片描边，但卡头没有「标题 + 总数 + 批量操作」那一条。视觉可接受，严格一致性上差一档。
3. **会员页筛选在标签内部**，未落进 `.list-card-filter` 灰色筛选带（其它 11 页在带内）。
4. **antd 预置色标签**（`<Tag color="blue">` 这类类型徽标）走 antd 自带调色板，不随主题主色变化——属状态分类色，刻意保留。
5. **Windows 实机观感仍未验证**：本地只有 macOS Chromium 截图；ClearType 下的字体渲染必须甲方目视。
6. 绘本风的手绘字体在**首次切换**时异步加载，约 1–2 帧内为系统字体（缓存后无感）。
