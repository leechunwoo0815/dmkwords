> 本文件由 `附录文末的生成命令` 扫描仓库生成；**它就是第九轮审查的覆盖台账**。
> 规则只有一条：**每一行都必须有判定**；判定可以在报告里被引用，但引用不能代替判定。


## 填法（图例）

| 列 | 含义 |
|---|---|
| 编号 | 稳定行号，报告里引用缺陷时写「台账 行号」，便于机器核对 |
| 资产 | 该行对应的具体资产（文件/端点/表/场景/页面/文档/FEAT/动线/轴） |
| 主责包 | 该资产的**主责**工作包（跨包交叉检查在各包各自声明，不代表他人可不看） |
| 覆盖要求 | `R1` = 必须**逐项独立判定**，禁止归并；`R2` = 必须一行判定，可用规则号归并（规则需在报告 §规则表 定义 + 反证抽样 ≥3 且写明抽样方法） |
| 判定 | `OK` / `P0`·`P1`·`P2`·`P3`（并给报告条目号）/ `VA`（不适用，必须写理由）/ `RG:<规则号>` / `MF`（变异失败，即发现"检查器抓不到"） |
| 证据 | 命令 / file:line / SQL 输出 / 探针名。**空 = 未判定 = 不合格** |

**覆盖率算术（报告必须自己算）**：按 A1–A18 分节给 `已判定行数 / 总行数`，并给总计。分母不接受"估计"，以本文件行数为准。

# 把 backend/common/base_model.py **docstring 示例**里的 `__tablename__ = "my_table"` 当成了真表。
# 改为 AST 只取**类体**里的赋值；并补上 DB 里真实存在、但不在模型里的框架表 alembic_version。
def model_tables() -> list[tuple[str, str]]:
    found: list[tuple[str, str]] = []
    for p in pyfiles(ROOT / "backend"):
        try:
            tree = ast.parse(p.read_text(encoding="utf-8"))
        except SyntaxError:  # pragma: no cover
            continue
        for node in ast.walk(tree):
            if not isinstance(node, ast.ClassDef):
                continue
            for stmt in node.body:
                target = None
                value = None
                if isinstance(stmt, ast.Assign) and len(stmt.targets) == 1:
                    target, value = stmt.targets[0], stmt.value
                elif isinstance(stmt, ast.AnnAssign):
                    target, value = stmt.target, stmt.value
                if getattr(target, "id", "") == "__tablename__" and isinstance(
                    value, ast.Constant
                ):
                    found.append((str(value.value), rel(p)))
    return sorted(set(found))

def parse_feature(p: pathlib.Path) -> tuple[bool, list[tuple[str, str, int, bool]]]:
    """返回 (是否整文件 @draft, [(场景名, LIVE/DRAFT, 展开后条数, 是否大纲)])。"""
    lines = p.read_text(encoding="utf-8").splitlines()
    file_draft = False
    for ln in lines:
        s = ln.strip()
        if re.match(r"^(功能|特性|Feature)[:：]", s):
            break
        if s.startswith("@draft"):
            file_draft = True
    rows: list[tuple[str, str, int, bool]] = []
    cur = False
    i = 0
    while i < len(lines):
        s = lines[i].strip()
        if s.startswith("@"):
            if s.startswith("@draft"):
                cur = True
            i += 1
            continue
        m = re.match(r"^(场景|场景大纲)[:：]\s*(.*)$", s)
        if m:
            is_outline = m.group(1) == "场景大纲"
            examples = 1
            if is_outline:
                j, got, count = i + 1, False, 0
                while j < len(lines):
                    t = lines[j].strip()
                    if re.match(r"^(例子|Examples)[:：]", t):
                        got = True
                        j += 1
                        continue
                    if got and t.startswith("|"):
                        count += 1
                        j += 1
                        continue
                    if got and count and not t.startswith("|"):
                        break
                    j += 1
                examples = max(count - 1, 0) or 1
            rows.append((m.group(2), "DRAFT" if (cur or file_draft) else "LIVE", examples, is_outline))
            cur = False
        i += 1
    return file_draft, rows
