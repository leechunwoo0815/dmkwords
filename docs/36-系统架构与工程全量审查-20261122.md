## §八 应用层安全面实测（优于预期——**限应用层**；管理面例外见 v2 新增 P1-8/9/10）

- `/docs`、`/redoc`、`/openapi.json` 外部**不可达**：nginx 只代理 `/api/` + `/health`，其余走 SPA 回退（实测返回 admin-web index.html，零 swagger 特征）——拓扑隔离 + `is_production_env` fail-closed 双保险；
- 401 响应带全套安全头（nosniff/XFO DENY/referrer-policy/HSTS）；
- 44 个文件服务端点路径穿越全核验无一缺口；SQL 注入面干净（LIKE 全转义、`text()` 全参数绑定）；出网收敛到 `api.weixin.qq.com`/`api.mch.weixin.qq.com` 两域；
- nginx「?token= 进访问日志」暴露**当前不成立**（`access_log off`，零写入），但代价是 HTTP 层完全不可观测（归入 P1-1）。**v2 警示**：日后开日志必须用不含 query 的 log_format（`$uri` 而非 `$request`），否则媒体 `?token=` 直接落盘——「开日志」与「token 安全」不是二选一，用对格式两者兼得（见 §九 ⑤′）。
