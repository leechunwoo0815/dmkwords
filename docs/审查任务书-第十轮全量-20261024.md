## 5. 缺陷分级（必须严格按此定级，不许一律 P3）

- **P0**：资金错账 / 数据丢失 / 全站不可用 / 越权拿到他人数据 / 隐私泄露。

- **P3**：文案/视觉/一致性/可维护性；**必须给"为什么不升 P2"的理由**。
