## 二、Windows 字体问题（根因）

1. `ZCOOL KuaiLe` 手绘感字体在 Windows 缺失 → 回退微软雅黑，但仍有 `font-weight: 800`/`letter-spacing`，字重和字距失真。
2. `Nunito` 只覆盖拉丁字符，中文回退微软雅黑；英文与中文的 x-height/基线不齐，显得"歪歪扭扭"。
3. 微软雅黑实际只有 regular/bold；`700/800` 会被合成加粗，ClearType 下发虚、发黑。
4. `--font-mono` 首选 `SF Mono`（Windows 无），回退 Consolas 尚可，但字距风格偏 mac。
5. 2px 粗边框 + 硬偏移阴影 + 999px 胶囊在 Windows 100% 缩放/普通屏上显得笨重。

**修法**：
- 移除 `@fontsource/zcool-kuaile` 与 `@fontsource/nunito` 的 6 个 import（`main.tsx`）。
- 字体栈统一为：
  `"Segoe UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif`
- 字重只用 **400 / 500 / 600**；标题 600，不用 800。
- 正文 14px / 行高 1.5；表格数字 `font-variant-numeric: tabular-nums`。
- 中文标题不加 `letter-spacing`；仅英文全大写短标签保留小字距。
- macOS 保留 `-webkit-font-smoothing: antialiased`；Windows 不依赖该属性。

- 圆角：控件 **6px**、卡片 **8px**、小标签 **4px**；取消 999px 胶囊。
- 边框：1px；取消 2px/2.5px 粗边框。
- 阴影：`0 1px 3px rgba(0,0,0,.06)`；取消硬偏移阴影。

- 去掉水彩纹理、wiggle 动画、手绘虚线、彩色硬阴影。

### 字体

- 字体栈见 §二；正文 14px，标题 16/18/20px，辅助 12px。
- 卡片标题 14px/600；页面标题 20px/600；数字用等宽数字特性。

### 空态/加载

- 卡通角色（书虫/星星/熊）替换为 **线性图标 + 一句说明**（antd 图标或自绘 1.5px 线性 SVG）。

## 八、实施记录（第一百六十四批，2026-11-04 完成阶段 0–2）

### 8.1 主题架构：换皮 = 换一个令牌对象

| 文件 | 作用 |
|---|---|
| `admin-web/src/theme/types.ts` | `ThemeTokens` 契约：颜色 / 形状 / 阴影 / 密度 / 字体 / 动效 六组令牌 |
| `admin-web/src/theme/enterprise.ts` | 默认主题「企业·飞书蓝」：`#3370FF`、紧凑 32px、1px 描边、6/8px 圆角、系统字体栈 |
| `admin-web/src/theme/index.ts` | `THEMES` 注册表 + `applyTheme()`（写 `<html>` CSS 变量与 `data-theme`）+ `buildAntdTheme()`（antd ThemeConfig）+ `getTheme()` |
| `admin-web/src/styles/paint.css` | 只写结构（骨架 / 表格滚动条 / 图表几何 / 图片预览），**不写任何颜色或尺寸常量** |

- 启动顺序：`main.tsx` 先 `applyTheme()` 再 render，首帧即带变量；`ConfigProvider` 从**同一份令牌**派生，杜绝「双份色板漂移」。
- 新增主题：加一个 `ThemeTokens` → 注册表登记 → `applyTheme(id)`；组件与 CSS 无需改动。
- 选择记忆：`localStorage["dmkwords.admin.theme"]`，非法值回落默认。
- 变量命名：`--color-*` / `--radius-*` / `--shadow-*` / `--control-height*` / `--font-*` / `--chart-1..6`。

### 8.5 图形区科技化（甲方追加要求，同一批）

> 甲方 2026-11-04 追加：「首页的各种图表样式也要更科技、更未来、更现代化」。
> 做法是**数据看板语言**（渐变 + 细网格 + 平滑曲线 + 等宽数字），不是发光/赛博特效——
> 后者会和刚定的企业风打架，也会在 Windows 低配机上拖帧。

| 图 | 改法 |
|---|---|
| 馆藏甜甜圈 | 每段独立**线性渐变**（实色 → 55% 透明，`userSpaceOnUse` 让整个环共用一次色扫）；段间留 6px 缺口；0 值不画弧只留图例；中心大号数字 + 弱化副标题；图例数值三列网格**右对齐** |
| 今日流量 | 数值移到柱顶（等宽特性）；柱体同色渐变；去 1px 描边，改浅底轨道 + 圆角 |
| 健康度 | 环形加渐变和**圆头线帽**，圆心数字带小号 `%`（单位弱化） |
| 借还趋势 | 折线改 **Catmull-Rom → 三次贝塞尔平滑**，并**限幅控制点**防过冲（原先平滑后会在全 0 平段画出负值下凹）；加 4 条虚线网格；面积渐变到透明；数据点带白描边 |
| 热门书 TOP5 | 排名改 `01/02/03`；条改 6px 高、**蓝→青渐变**圆角 |
| 小读者构成 | 堆叠条 12px 高、段间 2px 白分隔、圆角两端 |
| 卡片 | 标题 13px 次级色 + **主色小方块**锚点；hover 轻阴影；入场按列错开淡入（`prefers-reduced-motion` 下全关） |

**数字字体修正（重要）**：原先把数值设成 `--font-mono`（SF Mono / Cascadia），其 **0 带斜杠**，
「60」会被读成「6Ø」。现改为**正文字体 + `font-variant-numeric: tabular-nums`**：既竖向对齐又不误读；
等宽字体只保留给 antd 的 `fontFamilyCode`（配置键、代码片段）。

### 8.6 双主题 + 切换入口（甲方 2026-11-04 追加：「可以两个主题互相切换吗？」）

- **第二套主题**：`src/theme/paint.ts`「绘本风（旧）」——暖纸底 `#FDF8F0`、活力橙 `#FF6B35`、
  圆角 12/20/24 + 胶囊按钮（999）、2px 描边、硬偏移阴影、侧栏 240 / Header 64 / 控件 38。
- **切换入口**：右上角用户菜单 →「界面主题」→ 企业·飞书蓝 / 绘本风（旧），当前项高亮；
  下拉由 hover 改 **click**（触屏/远程桌面上 hover 菜单容易点不中）。
- **运行时**：`ThemeProvider` 保存当前主题 id；切换时**先同步写 CSS 变量**（不掉帧）再 `setState`
  让 `ConfigProvider` 换 antd token，两套皮肤一次到位；选择写入 `localStorage`，刷新/重开保持。
- **实测**：企业→绘本→刷新仍为绘本→切回企业，`data-theme` / `--color-primary` / 背景色逐步核对一致；
  绘本风下复核仪表盘与图书页，无白字白底、无不可读标签。

**复原范围（如实）**：做到了配色 / 圆角 / 描边 / 阴影 / 密度；**没做**手绘字体（ZCOOL+Nunito 依赖已删）、
水彩纹理、卡通插画、彩色图标圆圈——这几样不是令牌能表达的，需要组件级分支。所以它是「绘本风的配色与形态」，
不是像素级复刻。若甲方要 100% 还原，需要单独一批把插画/纹理组件按主题分支做回来。
