# 管理端企业级改版方案（2026-11-04，第一百六十四批待开工）

> **甲方决定**：不做明暗切换；把管理后台整体从「绘本风」改成**飞书/钉钉式企业级视觉**，显得专业。
> **已定参数**：主色 **飞书蓝 `#3370FF`**；控件密度 **舒适 36–38px**；卡通插画**换成简洁线性图标**。
> **使用环境优先 Windows 浏览器**（当前 Windows 下字体/观感差，必须在本次改版里解决）。
> 小程序端**不改**，继续保持现有风格。

## 二、Windows 字体问题（根因）

1. `ZCOOL KuaiLe` 手绘感字体在 Windows 缺失 → 回退微软雅黑，但仍有 `font-weight: 800`/`letter-spacing`，字重和字距失真。
2. `Nunito` 只覆盖拉丁字符，中文回退微软雅黑；英文与中文的 x-height/基线不齐，显得"歪歪扭扭"。
3. 微软雅黑实际只有 regular/bold；`700/800` 会被合成加粗，ClearType 下发虚、发黑。
4. `--font-mono` 首选 `SF Mono`（Windows 无），回退 Consolas 尚可，但字距风格偏 mac。
5. 2px 粗边框 + 硬偏移阴影 + 999px 胶囊在 Windows 100% 缩放/普通屏上显得笨重。

**修法**：
- 移除 `@fontsource/zcool-kuaile` 与 `@fontsource/nunito` 的 6 个 import（`main.tsx`）。
- 字体栈统一为：
  `"Segoe UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif`
- 字重只用 **400 / 500 / 600**；标题 600，不用 800。
- 正文 14px / 行高 1.5；表格数字 `font-variant-numeric: tabular-nums`。
- 中文标题不加 `letter-spacing`；仅英文全大写短标签保留小字距。
- macOS 保留 `-webkit-font-smoothing: antialiased`；Windows 不依赖该属性。

## 三、企业级设计 token（建议）

### 颜色

| 用途 | 值 |
|---|---|
| 主色 / hover / active | `#3370FF` / `#245BDB` / `#1A47B8` |
| 主色浅底 | `#E1EAFF` |
| 页面背景 | `#F5F6F7` |
| 卡片/容器 | `#FFFFFF` |
| 边框 / 分割线 | `#E5E6EB` / `#F0F1F2` |
| 主文字 / 次文字 / 弱文字 | `#1F2329` / `#646A73` / `#8F959E` |
| 成功 / 警告 / 危险 | `#00B42A` / `#FF7D00` / `#F53F3F` |
| 品牌橙（仅 Logo/点缀） | `#FF6B35` 保留，不做全局主色 |

### 形态与布局

- 圆角：控件 **6px**、卡片 **8px**、小标签 **4px**；取消 999px 胶囊。
- 边框：1px；取消 2px/2.5px 粗边框。
- 阴影：`0 1px 3px rgba(0,0,0,.06)`；取消硬偏移阴影。
- 间距：4/8/12/16/24；内容区 padding 20–24px。
- 侧栏 220–240px 白底 + 1px 右边框；Header 56px 白底 + 1px 下边框。
- 控件高度：默认 **36px**、大号 40px、小号 28px（甲方选"舒适 36–38"）。
- 表格：表头 44px、行高 48px、表头底色 `#F7F8FA`、行 hover `#F5F8FF`。
- 去掉水彩纹理、wiggle 动画、手绘虚线、彩色硬阴影。

### 字体

- 字体栈见 §二；正文 14px，标题 16/18/20px，辅助 12px。
- 卡片标题 14px/600；页面标题 20px/600；数字用等宽数字特性。

### 空态/加载

- 卡通角色（书虫/星星/熊）替换为 **线性图标 + 一句说明**（antd 图标或自绘 1.5px 线性 SVG）。
- `PaintLoading` 的抖动小人换 `Spin` 或简洁骨架屏；`PaintEmpty` 保留组件接口，内部换线性图标。

## 六、验收标准

1. `pnpm exec tsc --noEmit` 0 错；`pnpm build` 成功。
2. 全站主色 `#3370FF`；不再出现绘本感元素（水彩纹理/粗边框/硬阴影/999 胶囊/ZCOOL 标题）。
3. 控件默认 36px、卡片 8px 圆角、表格 1px 边框、页面背景 `#F5F6F7`。
4. 字体在 Windows 浏览器（Edge/Chrome）显示为 Segoe UI + 微软雅黑；中文标题无异常字距/合成粗体。
5. 登录、仪表盘、图书、会员、借阅、活动、订单、配置、任务、审计、通知每页截图（1366×768）无重叠/裁切。
6. 空态/加载态为线性图标或 `Spin`，不再出现卡通角色。

## 七、风险与未决

- `paint.css` 有 135 个 `!important` 覆盖，整文件重写可能影响未预料页面；采用分阶段 + 逐页截图，不一次性删除。
- antd token 与 CSS 变量存在"双份颜色"漂移风险；本次以 `theme-paint.ts` 为唯一色板来源，CSS 变量值与其逐项对齐并在代码注释登记。
- 本地是 macOS，**Windows ClearType/字体渲染最终必须甲方在 Windows 浏览器目视**；我只能提供 Chromium 截图与构建/类型验证。
- 空态组件 `character` 参数被多页调用，替换内部实现时保持 props 兼容，避免改调用方。
