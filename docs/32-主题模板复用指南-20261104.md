# 主题模板复用指南（2026-11-04，第一百六十四批产出）

> **目标（甲方原话）**：打造一套完整、可切换、可复用的管理端主题模板，以后别的项目能直接用。
> 本文说明"这套东西由什么组成 / 怎么加一套主题 / 怎么换项目 / 哪些还是本项目专属"。

---

## 一、分层（四层，边界要守住）

```
① 令牌层   src/theme/types.ts        主题契约（颜色/形状/阴影/密度/字体/动效）
           src/theme/<preset>.ts     每套皮肤一个对象（enterprise / paint / dark）
           src/theme/index.ts        注册表 + applyTheme()（写 CSS 变量）+ buildAntdTheme()
           src/theme/ThemeProvider   运行时（切换时先写变量再换 antd token）

② 样式层   src/styles/paint.css      结构样式（骨架/表格/图表几何/预览层），**零写死颜色**
           src/styles/skins/*.css    皮肤层，选择器全部限定 [data-theme="xxx"]

③ 组件层   components/PageHead       页头（标题 + 图标 + 说明 + 主操作）
           components/ListCard       列表卡（工具条 + 筛选带 + 标签 + 内容 + 分页）
           components/KpiTile        KPI 磁贴（图标 + 数值 + 单位 + 真实比例条）
           components/TechIcon       自绘图标集（20 个，currentColor + 主色锚点）
           components/PaintEmpty     空态（企业风线性 / 绘本风卡通，按主题分支）
           components/PaintLoading   加载态（Spin / 卡通）

④ 品牌层   src/branding.ts           名称/字标/副标题/登录说明/文档标题后缀
```

**换项目**：改 `branding.ts` + 换 `theme/<preset>.ts` 里的色板 → 组件、页面、CSS 都不用动。

**加一套皮肤**：

1. `theme/` 下新建一个 `ThemeTokens` 对象（照 `enterprise.ts` 抄，改颜色/圆角/密度）；
2. `theme/index.ts` 的 `THEMES` 与 `THEME_LIST` 各加一行；
3. 若这套皮肤有"令牌表达不了"的装饰（纹理、插画、胶囊、粗描边），
   新建 `styles/skins/<id>.css`，**所有选择器加 `[data-theme="<id>"]` 前缀**；
4. `main.tsx` 里 import 这个 skin 文件（只引 CSS，不写逻辑）。

现有三套：`enterprise`（企业·飞书蓝，默认）· `paint`（绘本风）· `dark`（大屏深色）。

## 二、三套主题的对齐矩阵（2026-11-04 实测）

| 元素 | 企业·飞书蓝 | 绘本风 | 大屏深色 |
|---|---|---|---|
| 页面壳（面包屑 / 五组侧栏 / 内容面） | ✅ 白纸 + 1px 描边 | ✅ 粗描边纸面 + 硬阴影 + 水彩纹理 | ✅ 深底 + 描边分层 |
| 页头（标题 + 自绘图标 + 说明 + 主操作） | ✅ 浅蓝圆角底 | ✅ 纸面圆框 + 墨线 | ✅ 同企业风 |
| 列表卡（工具条 / 筛选带 / 标签 / 分页） | ✅ | ✅ 虚线分隔 + 米黄筛选带 | ✅ |
| 表格 | ✅ 表头浅灰、行 1px 分隔 | ✅ **行卡片化**（行间留白 + 圆角描边） | ✅ 表头更深一档 |
| KPI 磁贴 | ✅ 1px 描边 + 轻阴影 | ✅ 2px 描边 + 硬阴影 | ✅ 底色抬升 |
| 仪表盘图形（趋势/仪表/环/榜/构成） | ✅ 细网格 + 渐变 | ✅ 同结构、橙绿黄配色、纸面网格 | ✅ 深底 + 数据线辉光 |
| 自绘图标（TechIcon） | ✅ 主色锚点 | ✅ 同图标，底色变纸面圆框 | ✅ 主色提亮 |
| 空态 / 加载态 | ✅ 线性图标 + Spin | ✅ **8 个卡通角色 / 7 个角色** | ✅ 同企业风 |
| 按钮 / 输入 / 标签 | ✅ 6px 圆角、1px | ✅ **胶囊 + 2px + 硬阴影** | ✅ 同企业风 |
| 登录页 | ✅ 品牌方块 + 白卡 | ✅ **黄色书本 + 手绘体标题** | ✅ 同企业风 |
| 字体 | 系统栈（Segoe UI / 雅黑） | **手绘体（懒加载 ZCOOL + Nunito）** | 系统栈，字号大一号 |
| antd 明暗算法 | defaultAlgorithm | defaultAlgorithm | **darkAlgorithm** |

> 结论：三套皮肤**共用同一套组件结构**，差异集中在令牌 + 皮肤 CSS；没有"某套主题缺一整块组件"的情况。

## 三、可直接搬走的组件（与业务无关）

| 组件 | 依赖 | 说明 |
|---|---|---|
| `theme/`（4 个文件） | antd | 令牌契约 + 注册表 + 切换运行时 |
| `styles/paint.css` | 无 | 结构样式（主题无关，只用变量） |
| `styles/skins/*.css` | 无 | 皮肤样式（按 `data-theme` 隔离） |
| `PageHead` / `ListCard` / `KpiTile` | antd | 列表页三件套 |
| `TechIcon` | 无 | 20 个自绘图标，纯 SVG |
| `PaintEmpty` / `PaintLoading` | antd | 按主题分支的空态/加载态 |
| `branding.ts` | 无 | 品牌文案单一来源 |

## 四、仍属本项目专属（搬走前要替换）

- `pages/*` 里的业务页面（图书/借阅/会员…）与 `api/`（后端契约）；
- `constant`s 里的业务枚举（会员状态、订单类型…）；
- 登录流程（`auth.tsx` 的 token 逻辑、`api/client.ts` 的拦截器）；
- `skins/paint.css` 里的卡通配色与手绘字体（想保留"绘本风"就一起搬，不需要就删该文件与 preset）。

## 五、纪律（改之前先读）

1. **CSS 不写死颜色/尺寸**：只准用 `var(--color-*)` / `var(--radius-*)` / `var(--control-height)` 等，否则换主题会"一半变一半不变"。
2. **皮肤 CSS 必须限定 `[data-theme="xxx"]`**：否则会和别的皮肤互相覆盖。
3. **antd 外观优先走 `buildAntdTheme`**，CSS 只处理 token 表达不了的结构。
4. **新增页面用 `PageHead` + `ListCard`**：手写页头会漏掉标题图标与统一间距（本项目踩过一次）。
5. **换主题必须同时换 antd token**：只改 CSS 变量会出现"卡片是新的、弹窗是旧的"。
