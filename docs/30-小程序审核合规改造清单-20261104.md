# 小程序审核合规改造清单（2026-11-04）

> **目标**：以「线下实体书店的会员借阅 / 到店预约工具」过审，不碰教育培训、不卖虚拟商品、当前不开线上支付。
> **一句话结论**：能过审的关键不是删功能，而是四件事——**类目匹配、支付入口清零、教育话术降噪、音频定位为随书配套**。
> 本文只做盘点与方案，未改代码；确认口径后按第一百六十三批实施。

## 一、审核最可能卡住的 5 件事（按风险排序）

| # | 风险 | 现状证据 | 为什么会被卡 |
|---|---|---|---|
| 1 | **服务类目与实际功能不符** | `app.json`：图书/书架/阅读圈/音频/小挑战/报告；当前类目只有「工具-预约/报名」 | 审核按"实际提供的服务"核类目；图书借阅、音频播放、阅读测评都不属于预约/报名 |
| 2 | **会员购买页仍展示价格与"在线支付"** | `member-pkg/purchase/purchase.wxml:9,14,26,32`；`purchase.js:75` | 即使支付通道关闭，页面看起来仍在"卖会员/卖权益"；虚拟商品+线上支付是审核红线 |
| 3 | **教育/测评话术密集** | 首页 `index.wxml:171`「让孩子爱上英文阅读」、`books.wxml:12/26/64` AR/年级、`observation-report.wxml:6/7`「评估报告/馆员评估」、`quiz-result.wxml:19`「答对 X / Y 题」 | 会被判为学科类培训/教育服务，需要办学许可或非学科培训资质 |
| 4 | **音频被认定为在线有声读物** | `reader`/`book-detail` 音频播放；会员即可听（`identity/guards.py:92` 只判会员态，不要求借到该书） | 「文娱-有声读物」要《网络文化经营许可证》等四选一；没有资质就不能做独立音频服务 |
| 5 | **儿童个人信息与隐私** | 收集家长手机号、孩子昵称/头像/年龄/年级、阅读数据；`privacy-policy.wxml:3` 还挂着「待法务审阅的占位文本」 | 微信要求隐私保护指引一致；不满 14 周岁需儿童个人信息规则/监护人同意 |

> 说明：「阅读圈」是**零 UGC**（`card_engine.py:11`：卡片全部后端生成，无用户文字/图片），这一项风险低，不需要删。

## 四、可以保留（并说明为什么）

| 模块 | 保留理由 |
|---|---|
| 首页 / 阅读空间 / 书架 / 我的 | 线下书店的藏书查询、借阅记录、会员服务入口 |
| 图书详情、借阅状态、预约、到馆取书 | 线下借阅服务的线上工具，属于「预约/报名」的自然延伸 |
| 借阅记录、押金台账、订单记录 | 线下交易的历史凭证；保留金额不构成线上售卖 |
| 押金页（只读台账 + 到店补缴） | 图书押金是线下借阅制度的一部分 |
| 活动列表/详情/报名/入场券 | 到店线下活动；费用到店缴纳 |
| 阅读进度、续播、配套音频 | 随**到店借阅的纸质书**提供的配套服务，不单独售卖、不下载、不设音频商城 |
| 阅读小挑战、词句收藏、打卡、徽章、排行榜、阅读圈 | 阅读记录与激励工具；阅读圈零 UGC（系统生成成就卡+点赞） |
| 消息中心、服务协议、隐私政策 | 必要的基础能力 |

**音频的定位要求（重要）**：
- 文案统一叫「**配套音频**」，不叫"听书/音频库/有声书"；
- 入口只在图书详情/播放器，不做音频列表、不做搜索、不做下载；
- 建议把收听资格从"会员即可听"收紧为「**当前有这本书的借阅记录**」或「到店借阅后」，
  审核问起时能一句话说清：这是纸质书借阅的配套服务，不是在线音频商品；
- 音频版权要能拿出授权/自制证明（审核可能问）。

## 五、类目与资质（决定能不能过）

微信官方类目（2026-11-04 查官方「服务类目」页）：

| 类目 | 资质 |
|---|---|
| 工具-预约/报名 | 无额外资质（当前已选） |
| 商家自营-图书报刊/音像/影视/游戏/动漫 | 零售需县（区）级《出版物经营许可证》 |
| 文娱-有声读物 | 《互联网出版许可证》/《网络出版服务许可证》/《信息网络传播视听节目许可证》/《网络文化经营许可证》四选一 |
| 教育服务-非学科类培训机构 | 办学许可证/非学科培训许可证/文化艺术类审核意见书/校外培训监管平台备案 |
| 教育服务-课程销售 | ICP 备案/增值电信许可证 + 营业执照（含教育咨询）+ 纠纷处理机制 |

### 方案 A（推荐）：有《出版物经营许可证》

- 类目：**商家自营-图书报刊/音像** + **工具-预约/报名**；
- 不加教育类目、不加有声读物；
- 音频按"随书配套"定位（不单独售卖）；
- 小程序名称/简介/截图统一为「线下书店会员借阅与到店预约」。

### 方案 B：没有《出版物经营许可证》

- 只靠「工具-预约/报名」风险很高：图书目录、借阅、音频都超出该类目；
- 诚实做法是**补办零售《出版物经营许可证》**（实体书店通常可办），或在提审版本里**移除图书/音频内容**（只剩预约/报名）；
- 不建议用"信息展示/工具"类目规避实际服务，审核看页面就能看出来。

### 不要选

- 教育类目（需要办学/培训资质，且会被按学科培训审查）；
- 文娱-有声读物（需要四类许可证之一），除非确实持有。

> **名称/简介/截图**：名称若含「英语/单词/学堂/教育/培训」，与工具类目冲突；简介写
> 「线下实体书店会员借阅、到店预约与活动报名工具；不提供线上课程、不销售虚拟商品、当前未开通线上支付」。
> 截图避免出现价格、测验分数、课程字样。

## 八、不确定项（如实）

- 审核是人工裁量，**无法保证一次过**；本文是降低概率，不是承诺。
- 音频是否被认定为「有声读物」取决于审核员对入口/资质的判断；若被要求资质，优先把音频收紧为
  "到店借阅配套"、必要时提审版本先隐藏音频入口（不建议长期两套逻辑）。
- 类目最终以公众平台可选列表为准；「图书借阅」若不在列表，只能走「商家自营-图书报刊」+ 工具类目组合。
- 儿童个人信息：需要《儿童个人信息保护规则》与监护人同意文案；当前隐私政策是占位文本，建议先找法务过一遍。
