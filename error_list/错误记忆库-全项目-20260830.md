## 一、本轮新增错误

### E-20260830-01 WXSS 中文类名卡死页面导航
- 事实：`.cat-资金` 类名使 navigateTo 直接 timeout（渲染错误吞掉导航响应），卡 20 分钟。
- 根因：WXSS 选择器用了中文类名。
- 修复：类名一律英文，中文文案进 data。
- **复发风险：高**（随手起名惯性）。防复发：**任何 WXSS 类名禁中文**。

### E-20260830-02 WXML 不支持 .split() 等方法调用
- 事实：picker 显示文本在 WXML 里调 .split() 无输出。
- 根因：WXML 表达式只支持简单运算/属性，不支持方法调用（与 C47 字符串下标同族）。
- 修复：js 预计算显示文本。
- 防复发：**WXML 只放 data 现成字段，转换逻辑全进 js**。

### E-20260830-03 seed_dictionary 全表拉内存（340 万行）
- 事实：`existing = {r[0] for r in query(DictionaryWord.word).all()}` 把 340 万行拉进 set，
  conftest 每个测试模块都调它，全量导入后 pytest 卡死 23 分钟（词库 309 词时不暴露）。
- 根因：`.all()` 全表拉取 + set 推导，无分页/IN 查询。
- 修复：改 IN 查询。
- **复发风险：中**（大表环境下的 .all()）。防复发：**大表全量去重判断必须用 EXISTS/IN，
  禁止 .all() 拉全表**。

### E-20260830-04 MP3 解析只覆盖 MPEG1
- 事实：4-5 秒音频显示 1 分多，永远无法读完；lame 低采样率输出 MPEG2 Layer III（fff3），
  解析器只认 MPEG1（fffb）→ 时长 0 → 兜底 60/90s → 完播判定不可达。
- 修复：file_storage.py 补 MPEG2/2.5 分支（低速率表/576 samples），重算 30 本入库。
- 防复发：**音频时长解析按帧头三版本全覆盖；新增音频源后抽样验证时长**。

### E-20260830-05 display:none + wx:if 组合弹层不可见
- 事实：quiz 确认弹层 `.confirm-overlay` 默认 display:none，wxml 却是 wx:if 条件渲染——
  wx:if 不渲染的节点永远不会有 .show 类，弹层永不显示。
- 修复：quiz.wxss 去掉 display:none。
- 防复发：**显隐二选一：wx:if（去掉 display:none）或 class 切换（去掉 wx:if）**。

### E-20260830-06 slider 刻度 Math.max(100, duration) + onCanplay 不触发
- 事实：4 秒音频 3 秒了滑块还在头上。两层根因：①sliderMax 强制 ≥100 → 滑块 3/100 看似不动；
  ②onCanplay 在部分基础库不触发，刻度不被真实时长替换。
- 修复：reader.js 三处（data 初始 0、onLoad Math.max(1,duration)、onTimeUpdate 时长校准兜底）。
- 防复发：**短音频刻度必须真实时长；onCanplay 不可依赖，onTimeUpdate 做兜底校准**。

### E-20260830-07 onEnded 时 currentTime 归零（最后一段进度丢失）
- 事实：4 秒音频播完服务端 intervals 只到 [0,3]，coverage 75%，finished 永远不触发
  （95% 判定差最后 1 秒）。onEnded 触发时 currentTime 已被基础库归零 → position(0)
  <= sessionStart → 跳过上报。
- 修复：onEnded 用 `audio.duration || this.data.duration` 兜底上报 endPos。
- **已验证（2026-08-30 深夜）**：模拟器播放 book2 5s → 库里 coverage=5/5、finished=1、
  intervals=[0,5]、last_position=5（推翻此前"模拟器时间不推进无法端到端"的边界声明——
  旧结论因 onCanplay/UI 触发路径差异得出，用 evaluate 触发 onTogglePlay 可正常推进）。
- 防复发：**上报终点的播放事件必须用 duration 兜底，禁取 currentTime（可能已归零）**。

### E-20260830-08 模拟器编译缓存假象
- 事实：wxml/wxss 改动后旧页面热重载不彻底，验证到旧 UI。
- 修复：先 simulator_refresh 再验证。
- 防复发：**改 wxml/wxss/js 后必 simulator_refresh，否则截图自查会骗人**。

### E-20260830-09 IDE 登录态过期
- 事实："模拟器连不上后端"第一嫌疑不是网络，是微信开发者工具登录态过期
  （MCP 报"需要重新登录"/APPID_ERROR）；扫码后 127.0.0.1 直通。
- 防复发：**连通性问题先 check_wechatide_status 看 loginExpired**。

### E-20260830-10 两个家长数据禁硬编码 child_id
- 事实：id=1 用户自注册 13800000914（"九九孩" child_id=1，无演示数据）、id=2 演示家长
  13800008888（"演示孩" child_id=2，全部演示数据挂这里）。本模型曾硬编码 child_id=1
  折腾半小时误报"日历无标记"。
- 防复发：**自动化必须从登录响应/session 的 currentChild.id 取 child_id，禁硬编码**。
  注意：当前库（2026-08-30 门禁清库重 seed 后）只有一个家长 id=1，演示数据挂 child_id=1——
  以实际登录态为准，勿依赖交接卡写的固定 id。

### E-20260830-11 onEnded 上报成功后 UI 百分比不刷新
- 事实：库里 finished=1/coverage=5/5 正确，但听书页 UI 仍显示"已覆盖 60%"。
- 根因：①onEnded 修复代码只 setData({playing:false})，未重新 loadProgress；
  ②补 loadProgress() 后仍有**竞态**——loadProgress 与最终上报并行，GET 先于 POST 落库
  拿到 60% 旧值。
- 修复：onEnded 里 `api.reportProgress(...).then(() => this.loadProgress())`——
  上报落库成功后再刷新 UI。
- **已验证（2026-08-30 晚）**：模拟器播放至 onEnded → UI 显示"已覆盖 100% + 已读完"、
  滑块到头（v6-onended-ui100.jpg）。二次竞态（页面复用后音频不可复播）用 reLaunch+navigateTo
  重建页面规避。
- 防复发：**上报终点的异步刷新必须 then 在上报 promise 之后，禁并行发 GET**。

### E-20260830-12 report_progress 对一维 intervals 脏数据 500
- 事实：验证重置进度时 intervals 误写 `[0,2]`（应 `[[0,2]]`），POST /reading/progress 500：
  `merge_intervals` 里 `i[1]` 对 int 抛 `TypeError: 'int' object is not subscriptable`。
- 根因：`service.py merge_intervals` 假设 intervals 恒为二维 `[[a,b]]`，遍历时一维元素
  （int）无下标。
- 修复（2026-08-30 晚，用户要求最健壮）：新增 `_clean_intervals()` 清洗函数——
  丢弃非 [a,b]、含非数字、start>=end、负起点的区间；`merge_intervals` 对任意脏输入
  清洗后合并；`json.loads(intervals)` 加 try/except（字段损坏按空区间）。
- 测试：`test_merge_intervals_dirty_data`（int/str/None/负区间/start>end/非 list 全场景）+
  `test_report_progress_polluted_intervals_no_500`（一维污染后上报 200，脏区间不入账）。
- 门禁 PASS 225/79.63%（gate-onended-defense.log）。
- **语义取舍（专家复核确认，随本条目固化）**：清洗丢弃的历史脏区间（如 [5,3] 倒序、
  [-1,2] 负起点）其非法覆盖时长**不回补**——当初真实听过的部分随清洗消失，孩子需重听
  才能补回覆盖率。这是防刷优先的正确取舍（覆盖统计宁少勿多），**非 bug，勿当 bug 报**。
- 防复发：**手动重置 reading_progress.intervals 必须用二维 `[[a,b]]` 格式；
  任何解析外部数据的分支都要做格式防御，禁裸 json.loads + 下标**。
