## 一、本轮新增错误

### E-20260828-01 Modal/按钮动画 transform 破坏 antd pointer-events 层级
- 事实：弹窗内所有按钮点了无反应（antd 5）。
- 被抓方式：用户手动验收点击失效；排查 `paint.css` 动画规则。
- 根因：`.ant-modal-wrap .ant-modal { animation: paint-bounce-in }` 含 `transform: scale()`，
  动画执行期间产生新层叠上下文，破坏 pointer-events 命中；`.ant-btn:active { transform:
  translate(...) }` 使按钮按下时移出鼠标点击区域。
- 修复：删除 Modal 自定义动画（回退 antd 自带动画）+ 删除按钮 `:active` 的 translate。
- **复发风险：中**（动画类 transform 改动容易随手再引入）。
- 防复发：**给 antd 组件加 animation/transform 前，先确认不影响 pointer-events/命中区域**；
  Modal 只动画 `.ant-modal-content` 且不破坏层级。

### E-20260828-02 macOS overlay 滚动条鼠标不可见，纯 CSS 无法强制
- 事实：BookManage 表格横向滚动条触摸板滑动才闪现，鼠标用户完全看不到右侧操作列。
- 被抓方式：headless Chrome 截图 + 像素采样，发现 `-webkit-scrollbar` 样式注入后截图仍无滚动条；
  用户实测两种方案（`-webkit-appearance:none`、StackOverflow 经典写法）均无效。
- 根因：macOS「滚动条：自动」= overlay 滚动条，隐藏直到发生滚动；`::-webkit-scrollbar`
  在 Chrome 部分版本/系统设置下无法覆盖 overlay 行为。
- 修复：**放弃原生滚动条**，新增 `PaintHScrollbar` 组件（可拖动 thumb + 点击轨道跳转），
  并在 `paint.css` 隐藏 `.ant-table-content::-webkit-scrollbar:horizontal`。
- **复发风险：低**（方案已定型）。
- 防复发：**macOS 上要"始终可见滚动条"，直接做 JS 自定义滚动条，不依赖 `::-webkit-scrollbar`**；
  改滚动条先问用户用的是鼠标还是触摸板。

### E-20260828-03 flex 子项内容过宽撑开整页布局
- 事实：表格横向滚动条消失，实为底部分页组件把内容区撑宽，`Content` 不再收缩。
- 被抓方式：headless Chrome 量 `.ant-layout-content` / 内层 `.ant-layout` 尺寸与 `min-width`。
- 根因：flex 布局子项默认 `min-width: auto`，内容（宽分页/宽表格）超过容器时不收缩。
- 修复：内层 `AntLayout` / `Content` 设 `minWidth: 0`。
- **复发风险：中**（新增 flex 容器时易忘）。
- 防复发：**flex 布局出现"内容撑破/不收缩"，先查子项是否缺 `min-width: 0`**。

### E-20260828-04 远程验证改 UI 不该凭猜连续试
- 事实：BookManage 滚动条问题连试 3 种 CSS 方案未定位，用户明确不满"你别瞎改"。
- 被抓方式：用户反馈无效；用 headless Chrome 实际量 DOM/截图才定位。
- 根因：用 headless Chrome 诊断但不看截图结论、凭经验猜改。
- 修复：先用 puppeteer 实测 DOM 尺寸/溢出再改；截图后 `image-analyzer` 识图（用户要求：
  具备多模态的模型直接读图，不要绕 image-analyzer）。
- **复发风险：高**（远程调试习惯）。
- 防复发：**改样式前先拿真实渲染数据（尺寸/overflow/截图），一次定位再动手**；
  连续两次试错未中就停下换诊断手段，禁止凭猜继续。

### E-20260828-05 固定路径媒体重传后浏览器缓存不刷新
- 事实：重传封面/音频后 uploads 有新文件，页面仍显示旧图/旧时长；刷新、重进仍旧
  （封面）；音频要退出重进才更新。
- 被抓方式：查 `apiMediaUrl` 返回固定 URL（`/cover-media?token=...`）；音频 `<audio>` src
  字符串不变被 React 复用。
- 根因：媒体存储固定文件名（`{code}.jpg` / `audio.mp3`）+ 前端 URL 无版本参数 → 浏览器/
  audio 元素按 URL 复用旧内容。
- 修复：文件名加随机后缀（重传生成新路径并删旧文件）；`apiMediaUrl(bookId, kind, version)`
  追加 `v=<文件路径>`，BookDetail 传 `book.cover_path` / `book.audio_path`。
- **复发风险：低**（方案已定型）。
- 防复发：**重传会覆盖的资源（图/音频/视频）URL 必须带内容版本参数，且每次上传生成新路径**；
  不要用固定文件名 + 固定 URL。

### E-20260828-06 整页随内容滚动导致侧边栏滑出
- 事实：左侧导航随内容下滑滚出屏幕。
- 被抓方式：用户反馈；检查 `Layout.tsx` 外层 `AntLayout` 只有 `minHeight: 100vh`。
- 根因：整页容器高度随内容增长，Sider 与 Content 在同一滚动流。
- 修复：外层 `height:100vh; overflow:hidden`；Sider `position:sticky; top:0; height:100vh`；
  Content `flex:1 1 auto; overflow:auto`。
- **复发风险：中**（新增后台页布局易退回整页滚动）。
- 防复发：**后台框架用"外层 100vh 固定 + 内容区独立 overflow:auto"**；发现侧边栏跟着滚
  就检查外层是否被内容撑高。

### E-20260828-07 antd Select 的 value 不在 options 中会显示英文原始值（R3 显示回归）
- 事实：BookDetail 副本状态下拉动态化后，`value={r.status}` 但 options 只含目标状态，
  available/maintenance/lost 行显示 "available" 等英文原始值（外部复核抓获）。
- 被抓方式：外部复核逐行核对；修复前用户看到的是英文。
- 根因：动态 options 时漏掉"当前值"本身；antd Select 找不到匹配项就渲染原始 value。
- 修复：options 头部加 `{ value: r.status, label: 中文标签, disabled: true }` 禁用首选项。
- **复发风险：中**（凡动态生成 options 都可能踩）。
- 防复发：**Select 的 options 必须恒包含当前 value（哪怕是 disabled 项）**；
  改完用浏览器实测每行显示，不能只看 tsc。

### E-20260828-08 数据处置后跑测试清库 → 处置证据与备份全被冲掉（证据链断裂）
- 事实：软删 9 本书后先跑了 pytest/gate（TRUNCATE 清库），后才做备份——备份里无书目、
  删除审计也被清，外部复核时"已删+留痕"完全不可核实；用户手动测试数据一并丢失。
- 被抓方式：外部复核索要证据，gate-runs 与备份均无法支撑。
- 根因：处置顺序错误。pytest/gate 的 clean_db 夹具会 TRUNCATE 共享 MySQL（项目既定行为），
  任何要在事后核查的数据/证据都必须在跑测试**之前**落盘。
- 修复：本次处置顺序改为——①备份 ②验证备份含数据 ③数据处置 ④处置证据落盘
  （审计导出/操作记录）⑤才允许跑 pytest/gate。
- **复发风险：高**（门禁高频跑，顺手就忘）。
- 防复发：**凡是"删数据/改数据 + 声称留痕"的操作：先备份并验证、证据落盘，最后才碰测试**；
  声称"含审计留痕"前确认该证据在后续测试清库后仍然可查（导出存 gate-runs/）。

### E-20260828-09 接口响应的派生字段未随写操作重算 → 前端展示退化（D1 missing 丢失）
- 事实：上传封面/音频后详情页「待完善」Tag 消失（应更新），刷新才恢复。
- 被抓方式：用户手动验收；对比"上传 Tag 消失、编辑保存正常（走 load 全量刷新）"定位差异。
- 根因：upload_cover/upload_audio 路由的 BookResponse 用 `_to_book_response(book, 0)` 默认
  missing=[]，未调 get_onboarding_missing 重算；前端 setBook(updated) 整体替换 state，
  派生字段被空值覆盖。
- 修复：三处写操作响应（上传×2 + update）重算 missing；前端上传成功改 load() 全量刷新兜底。
- **复发风险：中**（凡"响应模型含派生字段 + 前端整体替换 state"的组合都可能踩）。
- 防复发：**响应模型含派生/统计字段时，每个写操作端点必须显式重算；前端拿到写操作响应
  整体替换 state 前，确认派生字段在响应里是最新值，否则统一 load() 全量刷新。**

### E-20260828-10 脚本替换目标串失配静默失败 → 声称已更新实际未落盘（LEDGER 漂移）
- 事实：WM2 转 ACCEPTED 时用 python str.replace 更新 LEDGER WM2 行，目标串因先前追加过
  D1 文案已不匹配，replace 无操作；未验证即报告"已回写"，外部复核发现台账仍是 MANUAL_TEST。
- 被抓方式：外部复核逐行核对 LEDGER。
- 根因：①长目标串做 replace，脆弱；②违反 AGENTS"用脚本批量改文件后必须 grep 验证落盘"。
- 修复：改用行号断言式替换（assert lines[N].startswith(...)）+ 改后 rg 验证。
- **复发风险：高**（脚本改文档是高频动作）。
- 防复发：**脚本改文档：优先 edit 工具；用脚本则断言目标存在 + 改后 rg 验证关键行，两者缺一不可；
  声称"文档已更新"前必须看到验证输出。**

## 二、防复发红线（新增）

1. **antd 组件加 animation/transform 前确认不破坏 pointer-events/点击命中**（E-01）。
2. **macOS 要始终可见滚动条 → JS 自定义滚动条，不依赖 `::-webkit-scrollbar`**（E-02）。
3. **flex 布局内容不收缩 → 查子项 `min-width: 0`**（E-03）。
4. **样式 bug 先实测渲染数据再改，禁止连续试错**（E-04）。
5. **重传会覆盖的资源 URL 必须带内容版本参数 + 每次上传生成新路径**（E-05）。
6. **后台框架用"外层 100vh 固定 + 内容区独立 overflow:auto"，防侧边栏滑出**（E-06）。
7. **Select 动态 options 必须恒含当前 value（disabled 首选项），改完浏览器实测显示**（E-07）。
8. **数据处置 = 先备份验证 → 处置 → 证据落盘 → 最后才跑测试/门禁**（E-08）。
9. **写操作响应含派生字段必须重算；前端整体替换 state 前确认字段最新，否则 load() 兜底**（E-09）。
