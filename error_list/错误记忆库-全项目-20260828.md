## 一、本轮新增错误

### E-20260828-01 Modal/按钮动画 transform 破坏 antd pointer-events 层级
- 事实：弹窗内所有按钮点了无反应（antd 5）。
- 被抓方式：用户手动验收点击失效；排查 `paint.css` 动画规则。
- 根因：`.ant-modal-wrap .ant-modal { animation: paint-bounce-in }` 含 `transform: scale()`，
  动画执行期间产生新层叠上下文，破坏 pointer-events 命中；`.ant-btn:active { transform:
  translate(...) }` 使按钮按下时移出鼠标点击区域。
- 修复：删除 Modal 自定义动画（回退 antd 自带动画）+ 删除按钮 `:active` 的 translate。
- **复发风险：中**（动画类 transform 改动容易随手再引入）。
- 防复发：**给 antd 组件加 animation/transform 前，先确认不影响 pointer-events/命中区域**；
  Modal 只动画 `.ant-modal-content` 且不破坏层级。

### E-20260828-02 macOS overlay 滚动条鼠标不可见，纯 CSS 无法强制
- 事实：BookManage 表格横向滚动条触摸板滑动才闪现，鼠标用户完全看不到右侧操作列。
- 被抓方式：headless Chrome 截图 + 像素采样，发现 `-webkit-scrollbar` 样式注入后截图仍无滚动条；
  用户实测两种方案（`-webkit-appearance:none`、StackOverflow 经典写法）均无效。
- 根因：macOS「滚动条：自动」= overlay 滚动条，隐藏直到发生滚动；`::-webkit-scrollbar`
  在 Chrome 部分版本/系统设置下无法覆盖 overlay 行为。
- 修复：**放弃原生滚动条**，新增 `PaintHScrollbar` 组件（可拖动 thumb + 点击轨道跳转），
  并在 `paint.css` 隐藏 `.ant-table-content::-webkit-scrollbar:horizontal`。
- **复发风险：低**（方案已定型）。
- 防复发：**macOS 上要"始终可见滚动条"，直接做 JS 自定义滚动条，不依赖 `::-webkit-scrollbar`**；
  改滚动条先问用户用的是鼠标还是触摸板。

### E-20260828-03 flex 子项内容过宽撑开整页布局
- 事实：表格横向滚动条消失，实为底部分页组件把内容区撑宽，`Content` 不再收缩。
- 被抓方式：headless Chrome 量 `.ant-layout-content` / 内层 `.ant-layout` 尺寸与 `min-width`。
- 根因：flex 布局子项默认 `min-width: auto`，内容（宽分页/宽表格）超过容器时不收缩。
- 修复：内层 `AntLayout` / `Content` 设 `minWidth: 0`。
- **复发风险：中**（新增 flex 容器时易忘）。
- 防复发：**flex 布局出现"内容撑破/不收缩"，先查子项是否缺 `min-width: 0`**。

### E-20260828-04 远程验证改 UI 不该凭猜连续试
- 事实：BookManage 滚动条问题连试 3 种 CSS 方案未定位，用户明确不满"你别瞎改"。
- 被抓方式：用户反馈无效；用 headless Chrome 实际量 DOM/截图才定位。
- 根因：用 headless Chrome 诊断但不看截图结论、凭经验猜改。
- 修复：先用 puppeteer 实测 DOM 尺寸/溢出再改；截图后 `image-analyzer` 识图（用户要求：
  具备多模态的模型直接读图，不要绕 image-analyzer）。
- **复发风险：高**（远程调试习惯）。
- 防复发：**改样式前先拿真实渲染数据（尺寸/overflow/截图），一次定位再动手**；
  连续两次试错未中就停下换诊断手段，禁止凭猜继续。

## 二、防复发红线（新增）

1. **antd 组件加 animation/transform 前确认不破坏 pointer-events/点击命中**（E-01）。
2. **macOS 要始终可见滚动条 → JS 自定义滚动条，不依赖 `::-webkit-scrollbar`**（E-02）。
3. **flex 布局内容不收缩 → 查子项 `min-width: 0`**（E-03）。
4. **样式 bug 先实测渲染数据再改，禁止连续试错**（E-04）。
