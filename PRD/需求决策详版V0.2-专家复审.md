# DmkWords 需求决策详版 V0.2.1 正式规则修订稿

本文件是《需求决策详版 V0.2》的正式补充与修正稿。

开发时必须遵循以下原则：

```text
1. V0.2 中已明确且与本文件不冲突的规则继续有效。

```

# 一、会员生命周期正式规则

## R-100：会员生命周期状态机

系统必须维护学生会员状态，状态仅允许以下六种：

```text
none                 未入会
observation          观察期会员
pending_evaluation   待评估
formal               正式会员
expired              已过期
withdrawn            已退会
```

状态流转规则：

```text
none → observation
  条件：观察期费订单支付确认成功。

none → formal
  条件：家长直接购买正式年费并支付确认成功。

observation → pending_evaluation
  条件：观察期到期，系统自动流转。

pending_evaluation → formal
  条件：馆员操作评估通过，且正式年费订单支付确认成功。

formal → expired
  条件：正式会员到期且未续费。

observation / pending_evaluation / formal / expired → withdrawn
  条件：退会流程完成。
```

开发口径：

```text
1. 会员状态必须与学生档案绑定，每个学生一条会员状态。
2. 订单支付确认时间决定会员开始时间。
3. 待支付、待人工确认订单不得开通会员权益。
4. 会员状态变更必须写入会员状态变更日志。
```

---

## R-101：观察期有效期与待评估规则

观察期固定为：

```text
30 天
```

观察期开始时间：

```text
观察期费订单支付确认时间
```

观察期到期后：

```text
系统自动将会员状态置为 pending_evaluation。
```

待评估状态规则：

```text
1. 待评估期间保留全部会员权益。
2. 待评估状态无自动失效时间。
3. 待评估学生仍属于“在册会员”。
4. 系统每周生成“待评估超过 7 天”的跟进名单。
5. 待评估学生转正必须支付正式年费。
```

---

## R-102：观察期退费正式规则

观察期费 500 元的退费规则按以下口径执行：

```text
1. 仅在 observation 状态下申请退会时，观察期费可按剩余天数退还。
2. 观察期到期后进入 pending_evaluation 状态，观察期费不再退还。
3. 待评估状态退会时，仅处理押金退还，不退观察期费。
```

观察期内退费公式：

```text
观察期可退金额 = 实付观察期金额 × 剩余观察期天数 ÷ 30
```

剩余观察期天数计算：

```text
剩余观察期天数 = 观察期到期日 - 退会申请日
最小为 0。
不足一天按 0 天计算。
```

正式规则：

```text
观察期到期后进入待评估，再申请退会：
  观察期费 = 0
  押金 = 校验无遗失、损坏、逾期、未结赔偿后全额退还
```

---

## R-103：正式年费退费正式规则

正式年费按剩余天数退费。

退费公式：

```text
正式年费可退金额 = 实付年费金额 × 剩余会员天数 ÷ 365
```

剩余会员天数：

```text
剩余会员天数 = 会员到期日 - 退会申请日
最小为 0。
不足一天按 0 天计算。
```

规则：

```text
1. 退费金额按实付金额计算。
2. 二孩 9 折后实付 5400，则按 5400 计算。
3. 不收取手续费。
4. 已参加活动费用不退。
5. 押金不参与年费抵扣。
6. 押金单独按押金规则退还。
```

---

## R-104：续费生效规则

正式会员续费生效规则：

```text
1. 若续费支付确认时间早于当前会员到期日：
   新到期日 = 当前会员到期日 + 365 天。

2. 若续费支付确认时间晚于或等于当前会员到期日：
   新到期日 = 支付确认日 + 365 天。
```

观察期转正正式会员：

```text
正式会员开始日 = 年费支付确认日
正式会员到期日 = 支付确认日 + 365 天
```

# 二、押金与赔偿正式规则

## R-110：押金状态机

押金按学生收取，每个学生一条独立押金记录。

押金金额默认：

```text
1200 元
```

押金状态：

```text
unpaid              未缴
paid                已缴
partially_deducted  已部分扣除
refunding           退款中
refunded            已退款
fully_deducted      已全部扣除
```

押金字段必须包含：

```text
student_id
deposit_amount      押金金额
deducted_amount     已扣金额
available_amount    可用余额
frozen_amount       冻结金额
status
paid_at
refund_apply_at
refunded_at
```

规则：

```text
1. 押金未缴不允许线上预约。
2. 押金未缴线下借书仅软提示，可人工放行。
3. 押金部分扣除后，系统提示“押金不足，待补缴”。
4. 押金不足不硬拦截线下借书，但必须提示馆员。
5. 押金退款前必须校验该学生借阅、遗失、损坏、赔偿情况。
```

---

## R-111：赔偿扣减押金规则

图书遗失或损坏赔偿默认按图书原价计算。

赔偿流程：

```text
1. 馆员创建赔偿记录。
2. 系统优先从该学生押金可用余额中扣减。
3. 押金足够：
   deducted_amount 增加；
   available_amount 减少；
   押金状态变为 partially_deducted 或 fully_deducted。
4. 押金不足：
   押金可用余额扣至 0；
   不足部分生成待结清赔偿记录。
```

赔偿记录字段：

```text
student_id
book_copy_id
book_id
loss_type             lost / damaged
original_price
compensation_amount
deposit_deducted_amount
remaining_amount
status                pending / settled
handler_id
handled_at
remark
```

规则：

```text
1. 赔偿只影响该学生本人押金，不影响兄弟姐妹押金。
2. 待结清赔偿未处理时，退会校验不通过。
3. 待结清赔偿不硬拦截线下借书，但必须持续提示。
4. 押金退款中新增赔偿时，不打断已发起的退款流程。
5. 退款申请时系统必须冻结押金退款快照金额。
6. 退款后新增赔偿进入待结清赔偿，由线下处理。
```

---

## R-112：退会流程状态机

退会必须作为独立流程管理，不允许直接修改会员状态。

退会状态：

```text
none              未申请退会
applying          退会申请中
pending_settle    待结算
refunding         退款中
completed         退会完成
cancelled         退会取消
```

退会校验：

```text
申请退会时必须校验该学生：
1. 无借阅中图书；
2. 无逾期未还图书；
3. 无未处理遗失；
4. 无未处理损坏；
5. 无待结清赔偿。
```

若校验不通过：

```text
系统不允许线上完成退会。
线下可人工协商处理。
后台可创建“人工退会处理记录”，必须填写原因。
```

退会完成后的状态：

```text
学生会员状态 = withdrawn
押金状态 = refunded 或 fully_deducted
该学生不再拥有任何会员权益。
```

# 三、图书、书目、副本与资源正式规则

## R-120：书目上下架状态

书目 Book 必须增加状态字段：

```text
active      上架
inactive    下架
```

书目下架规则：

```text
1. 下架后小程序不展示该书目。
2. 下架后不可新借。
3. 下架后不可预约。
4. 下架后音频停止播放。
5. 下架后未开始的 Quiz 不可开始。
6. 下架后已开始但未提交的 Quiz 作废。
7. 已提交的 Quiz 成绩保留。
8. 已入账有效词数、积分、阅读时长、打卡不回收。
9. 已借出图书仍需归还。
```

书目恢复上架：

```text
书目恢复 active 后，音频、借阅、预约、Quiz 可用状态重新生效。
历史数据不受影响。
```

---

## R-121：ISBN 与无 ISBN 图书规则

第一阶段图书录入原则上必须有 ISBN。

但系统必须支持异常无 ISBN 场景：

```text
1. 有 ISBN 图书：
   ISBN 为书目唯一业务键。

2. 无 ISBN 图书：
   系统生成内部书目编码：
   NOISBN-{yyyymmdd}-{seq}

3. 无 ISBN 图书必须标记：
   no_isbn = true

4. 无 ISBN 图书不允许通过 Excel 批量导入。
   仅允许后台单本录入。

5. 无 ISBN 图书现场借还不能依赖扫码 ISBN。
   馆员通过书名、内部编码或学生借阅清单人工选择。
```

副本规则：

```text
每个实体副本必须有系统内部唯一 copy_code。
copy_code 格式：DM-{8位序号}
第一阶段不打印 copy_code。
copy_code 是副本最终唯一键。
ISBN 仅用于书目识别和现场扫码入口。
```

---

## R-122：图书资源上传规则并入

图书封面、音频上传必须按以下规则执行：

```text
1. 新增图书表单内上传封面、音频时，必须先有合法 ISBN。
2. 表单阶段上传仅写入对象存储，不写入 books 表。
3. 保存图书时，后端根据最终 ISBN 检查对象存储资源。
4. 已存在图书编辑页上传资源时，直接覆盖对象存储并同步更新数据库。
5. 批量上传资源必须使用同一套路径规则。
6. 同一 ISBN 的封面、音频重复上传时直接覆盖。
```

封面路径：

```text
cover/{isbn前4位}/{isbn13}.jpg
```

音频路径：

```text
book_audio/{isbn13}/audio.mp3
```

规则：

```text
1. 封面仅支持 JPG/JPEG。
2. 音频仅支持 MP3。
3. 音频上传后必须解析时长。
4. 音频时长解析失败时，该音频不得用于阅读完成判定。
5. 后台应展示“时长解析失败，请重新上传”。
```

---

## R-123：音频资源状态

每本书目第一阶段仅允许一个主音频。

音频状态：

```text
none        未上传
uploaded    已上传待上架
online      已上架
offline     已下架
```

规则：

```text
1. 音频必须属于书目，不属于副本。
2. 音频上架后学生可播放。
3. 音频下架后学生不可播放。
4. 音频下架保留已有播放进度。
5. 音频恢复上架后，学生从原进度继续播放。
6. 音频替换必须记录操作日志。
```

---

## R-124：音频替换正式规则

音频替换时必须比较新旧音频时长。

规则：

```text
新音频时长与原音频时长差异 ≤ 5%：
  保留学生已有播放进度。
  若学生累计覆盖超过新音频时长，则按新音频时长截断。
  完成判定按新音频时长重新校验 95%。

新音频时长与原音频时长差异 > 5%：
  系统重置该书目下所有学生的音频播放进度。
  重置前后台必须弹出二次确认。
  重置必须记录操作日志。
```

后台提示文案：

```text
新音频时长与原音频差异较大，继续替换将重置所有学生阅读进度。是否继续？
```

# 四、借阅、逾期、续借正式规则

## R-130：借阅上限与逾期扣减公式

全局默认借阅上限：

```text
30 本
```

借阅周期：

```text
30 天
```

续借：

```text
每本书最多续借 1 次。
续借周期 7 天。
续借从原到期日开始计算。
```

逾期可借上限公式：

```text
effective_borrow_limit = max(0, 30 - 当前逾期未还数量)
```

可再借数量公式：

```text
available_borrow_count =
  effective_borrow_limit
  - 当前借阅中数量
  - 当前预约锁定数量
```

最小为 0。

---

## R-131：逾期借书与人工放行规则

线上规则：

```text
学生存在逾期未还图书时：
  小程序预约禁止。
  小程序自助续借禁止。
```

线下规则：

```text
学生存在逾期未还图书时：
  馆员端借书必须提示异常。
  馆员可人工放行本次借书。
  放行必须填写原因。
  系统记录操作人、时间、逾期数量、超额情况。
```

人工放行边界：

```text
1. 人工放行仅豁免“逾期异常提示”。
2. 人工放行不修改借阅上限公式。
3. 若 available_borrow_count = 0，馆员仍可人工超借。
4. 人工超借后，当前借阅中数量允许大于 effective_borrow_limit。
5. 后续线上预约、自助续借仍按实际借阅数量计算。
```

---

## R-132：续借正式规则

线上自助续借：

```text
允许家长/学生在小程序自助续借。
自助续借必须同时满足：
1. 学生会员状态为 observation / pending_evaluation / formal。
2. 该书当前未逾期。
3. 该学生无其他逾期未还图书。
4. 该书续借次数为 0。
5. 押金状态不为 unpaid。
```

线下馆员续借：

```text
馆员可为学生续借。
已逾期图书默认禁止续借。
馆员可人工放行逾期续借。
人工放行必须填写原因。
```

强制规则：

```text
无论线上还是线下，每本书最多续借 1 次。
人工放行不得突破续借次数限制。
```

续借到期日计算：

```text
new_due_date = 原 due_date + 7 天
```

---

## R-133：会员过期后的借阅规则

会员过期后：

```text
1. 不能线上预约。
2. 不能自助续借。
3. 不能线上主动新借。
4. 已借图书仍需归还。
5. 已借未还图书音频可继续播放。
6. 已借未还图书归还后，过期会员失去该书音频权限。
7. 已完成音频但未测验的图书，过期后仍可完成 Quiz。
8. 过期会员 Quiz 通过后，有效词数仍可入账，除非学生已退会。
```

线下人工借书：

```text
过期会员到店借书时，馆员端提示“会员已过期”。
馆员可人工放行借书。
放行必须填写原因。
系统自动生成“待续费跟进”站内提醒给运营专员。
```

# 五、预约借书正式规则

## R-140：预约对象与副本分配

家长在小程序预约时，预约对象为书目，不允许选择副本。

系统必须自动分配副本：

```text
1. 系统查询该书目下状态为 available 的副本。
2. 若存在可用副本，系统自动选择其中一个副本锁定。
3. 该副本状态变为 reserved。
4. 预约单记录该副本 ID。
5. 若无可用副本，预约失败。
```

第一阶段副本选择策略：

```text
按 copy_code 升序选择第一个 available 副本。
```

---

## R-141：预约限制规则

预约前置硬校验：

```text
1. 学生会员状态必须为 observation / pending_evaluation / formal。
2. 押金状态不能为 unpaid。
3. 学生当前不能存在逾期未还图书。
4. 当前借阅中数量 + 当前预约锁定数量 ≤ effective_borrow_limit。
5. 该学生同一书目当前不能存在 active 借阅记录。
6. 该学生同一书目当前不能存在 locked 预约单。
7. 该书必须处于 active 上架状态。
8. 该书必须有 available 副本。
```

任一条件不满足，预约失败。

---

## R-142：预约锁定与释放规则

预约锁定时长默认：

```text
72 小时
```

可配置：

```text
reservation_lock_hours = 72
```

预约单状态：

```text
locked        锁定中
checked_out   已到店借出
expired       超时未核销
cancelled     用户取消
exception     副本异常待处理
```

释放规则：

```text
预约锁定截止时间到达后：
  若状态仍为 locked：
    预约单状态 = expired
    副本状态 = available
    释放预约占用额度
```

用户取消：

```text
家长可取消 locked 状态预约。
取消后副本释放。
```

---

## R-143：预约副本异常处理

若预约锁定期间，该副本被转为 maintenance 或 lost：

```text
系统必须尝试自动切换到同书目其他 available 副本。
```

处理规则：

```text
1. 若存在其他 available 副本：
   原副本释放或保持异常状态；
   新副本状态 = reserved；
   预约单更新副本 ID；
   锁定截止时间不变。

2. 若不存在其他 available 副本：
   预约单状态 = exception；
   释放预约额度；
   通知馆员和家长；
   馆员可取消预约或后续重新分配。
```

---

## R-144：预约核销规则

学生到店借书时，如果存在该书目的 locked 预约单：

```text
必须优先核销预约单。
```

核销规则：

```text
1. 预约单状态 = checked_out。
2. 副本状态 = borrowed。
3. 同事务生成借阅记录。
4. 借阅到期日 = 借出日 + 30 天。
5. 预约核销后释放预约额度占用，转为借阅额度占用。
```

如果预约已过期：

```text
系统不得自动恢复预约。
馆员可按普通线下借书流程处理。
```

# 六、音频阅读进度与打卡正式规则

## R-150：音频完成判定规则

音频完成判定必须基于累计有效播放覆盖区间。

完成条件：

```text
累计有效播放覆盖时长 ÷ 音频总时长 ≥ 95%
```

配置项：

```text
audio_finish_threshold = 0.95
```

规则：

```text
1. 系统记录学生实际播放过的音频时间区间。
2. 多个区间取并集。
3. 重复播放同一区间不重复累计。
4. 拖动进度条跳过的部分不计入覆盖。
5. 倍速播放按音频原始时间轴计算覆盖。
6. 阅读时长按音频原始时长记录。
```

---

## R-151：播放进度上报与防刷规则

客户端必须上报播放进度。

上报时机：

```text
1. 播放开始后每 10 秒上报一次。
2. 暂停时上报。
3. seek 拖动后上报。
4. 退出页面时上报。
5. 切换倍速时上报。
```

上报字段：

```text
student_id
book_id
audio_id
session_id
current_position
playback_rate
client_timestamp
```

服务端防刷规则：

```text
1. 单次上报新增覆盖时长不得超过：
   服务端时间差 × 最大倍速 2.0 × 容差 1.2。

2. 超过阈值的异常段不得计入有效覆盖。

3. 连续 3 次异常上报，系统标记该书音频进度异常。
   学生端提示“播放进度异常，请重新播放”。

4. 异常进度不得触发读完、打卡、Quiz 解锁。
```

---

## R-152：首次读完触发规则

同一学生同一书目首次达到音频完成条件时，必须一次性触发：

```text
1. 阅读进度状态 = finished。
2. first_completed_at = 当前时间。
3. 累加阅读时长 = 音频原始时长。
4. 生成当日打卡记录。
5. 解锁该书 Quiz。
6. 发送阅读完成通知。
```

幂等规则：

```text
同一学生同一书目只能有一次首次读完触发。
重复达到 95% 不重复累加阅读时长。
重复达到 95% 不重复打卡。
重复达到 95% 不重复解锁 Quiz。
```

---

## R-153：打卡正式规则

打卡定义：

```text
当天存在任一本书首次完成音频阅读，即生成当日打卡。
```

唯一约束：

```text
同一学生同一自然日最多一条打卡记录。
同一学生同一书目终身只产生一次首次读完打卡。
```

规则：

```text
1. 同一本书同一天重复听完，不重复打卡。
2. 同一本书不同天重复听完，不重新打卡。
3. 一天首次读完多本书，仍只生成一条当日打卡。
4. 无音频书无法触发打卡。
5. 打卡按达成时刻所在自然日计算。
6. 跨零点完成时，按完成时刻所在日期计打卡。
```

连续打卡：

```text
连续打卡按自然日连续计算。
某自然日无打卡，则连续天数归零。
已发放积分不回收。
```

# 七、Quiz 正式规则

## R-160：Quiz 解锁条件

Quiz 解锁条件：

```text
学生 × 书目 的阅读进度状态 = finished
```

Quiz 不依赖还书状态。

```text
还书不是 Quiz 解锁条件。
未还书也可以 Quiz。
已还书也可以 Quiz。
```

无音频书：

```text
无法完成音频阅读。
Quiz 不解锁。
有效词数不入账。
```

## R-161：题库管理规则

题目必须支持以下字段：

```text
question_id
book_id
question_type       single_choice / true_false
content
options
correct_answer
sort_order
status              enabled / disabled
created_at
updated_at
```

组卷规则：

```text
第一阶段固定取该书目下状态为 enabled、sort_order 最小的前 5 题。
```

题目不足规则：

```text
若启用题目不足 5 题，该书 Quiz 不开放。
学生端提示“测验题准备中”。
```

题目修改规则：

```text
1. 题目不允许物理删除，只能停用。
2. 题目内容或答案修改不影响历史提交成绩。
3. 新提交使用最新启用题目。
4. 已提交记录必须保留题目快照。
```

---

## R-162：Quiz 次数与提交规则

Quiz 机会：

```text
每个学生 × 每本书目终身 3 次提交机会。
重新借阅不重置。
```

提交规则：

```text
1. 只有提交成功才扣减次数。
2. 未提交的退出不扣次数。
3. 草稿不保存。
4. 退出后再次进入必须重新答题。
5. 提交接口必须幂等。
6. 网络失败导致提交未成功，不扣次数。
```

次数状态：

```text
remaining_attempts = 3 - 已成功提交次数
```

用尽规则：

```text
3 次提交均未通过：
  Quiz 状态 = failed
  学生端显示“测验机会已用完”
  不计入有效词数
  不计入积分
```

---

## R-163：Quiz 提交快照规则

每次成功提交必须生成 `quiz_attempt` 记录。

记录字段：

```text
attempt_id
student_id
book_id
submit_time
score
passed
remaining_attempts_after
question_snapshot
student_answers
correct_answer_snapshot
```

题目快照必须包含：

```text
question_id
question_type
content
options
correct_answer
```

规则：

```text
1. 历史成绩永远以提交时快照为准。
2. 后续题目修改不影响历史成绩。
3. 题目停用不影响历史成绩展示。
```

---

## R-164：Quiz 成绩与通过规则

得分计算：

```text
score = 答对题数 ÷ 5 × 100
```

可能得分：

```text
0 / 20 / 40 / 60 / 80 / 100
```

通过条件：

```text
score ≥ 80
```

最高分规则：

```text
该书最终成绩 = 历史提交最高分。
最终成绩 ≥80 即视为通过。
```

积分补差规则：

```text
Quiz 加分仅在首次通过时发放。
重测更高分不补积分差额。
```

---

## R-165：Quiz 重置规则

后台可重置 Quiz 次数。

权限规则：

```text
第一阶段仅超级管理员可重置 Quiz 次数。
```

重置规则：

```text
1. 重置后 remaining_attempts = 3。
2. Quiz 状态 = not_started。
3. 历史提交记录保留。
4. 重置必须记录操作人、时间、原因。
5. 重置次数不等于人工通过。
6. 系统禁止任何角色直接将 Quiz 标记为 passed。
```

---

## R-166：Quiz 与会员状态、图书状态规则

会员状态：

```text
1. 未入会学生不可 Quiz。
2. 在册会员可 Quiz。
3. 过期会员可完成已解锁 Quiz。
4. 退会会员不可 Quiz。
5. 退会前已通过的成绩和有效词数保留。
```

有效词数入账：

```text
Quiz passed 时：
  若学生会员状态不为 withdrawn：
    入账有效词数。
  若学生已退会：
    不入账。
```

书目下架：

```text
书目 inactive 后：
  未开始的 Quiz 不可开始。
  已开始未提交的 Quiz 作废。
  已提交成绩保留。
  已入账有效词数保留。
```

# 八、积分、有效词数、排行榜正式规则

## R-170：有效词数入账规则

有效词数入账条件：

```text
1. 学生 × 书目 Quiz 状态 = passed。
2. 学生未退会。
3. 同一学生 × 同一书目仅入账一次。
```

入账字段：

```text
student_id
book_id
quiz_attempt_id
word_count
occurred_at
```

唯一约束：

```text
unique(student_id, book_id)
```

规则：

```text
1. 同一本书重复借阅不重复入账。
2. 同一本书重测通过不重复入账。
3. 已入账有效词数不回收。
4. 图书遗失不回收有效词数。
5. 图书下架不回收有效词数。
6. 会员过期不回收有效词数。
7. 退会后不再新增有效词数，但历史保留。
```

---

## R-171：词数积分折算规则

学生必须维护词数零头池：

```text
word_pool
```

每次有效词数入账时：

```text
word_pool = word_pool + 本次入账词数
new_points = floor(word_pool ÷ 100)
word_pool = word_pool % 100
```

规则：

```text
1. 每满 100 词发放 1 积分。
2. 零头保留。
3. 积分发放必须与有效词数入账同一事务或最终一致。
4. 同一本书不重复发放词数积分。
```

---

## R-172：Quiz 积分规则

Quiz 通过加分：

```text
首次通过时：
  score = 80 → +5 积分
  score = 100 → +10 积分
```

规则：

```text
1. 80 分与 100 分奖励互斥。
2. 仅首次通过该书时发放。
3. 重测更高分不补差。
4. 未通过不发放。
5. 后台重置次数后重新通过，不重复发放。
```

---

## R-173：连续打卡积分规则

连续打卡 7 天：

```text
每满 7 天发放 10 积分。
即第 7、14、21、28、35…… 天发放。
```

连续打卡 30 天：

```text
每连续满 30 天额外发放 50 积分。
即第 30、60、90…… 天发放。
```

规则：

```text
1. 第 30 天同时满足 7 天周期与 30 天奖励时，发放 10 + 50 = 60 积分。
2. 中断后连续天数归零。
3. 已发放积分不回收。
4. 打卡积分必须生成积分流水。
```

---

## R-174：积分账户规则

积分账户规则：

```text
1. 积分最低为 0。
2. 积分不允许负数。
3. 积分永久有效。
4. 积分不可转赠。
5. 积分明细对家长可见。
6. 人工调整必须记录操作人、原因、调整金额。
7. 第一阶段仅超级管理员可人工调整积分。
```

---

## R-175：排行榜参与范围

排行榜仅展示当前在册学生。

在册学生定义：

```text
会员状态 ∈ {observation, pending_evaluation, formal}
```

规则：

```text
1. 过期学生不展示在周期榜。
2. 退会学生不展示在任何榜单。
3. 过期学生续费恢复在册后，可重新展示。
4. 历史有效词数保留，但非在册期间不参与榜单展示。
```

---

## R-176：榜单类型与统计口径

本期榜单：

```text
周榜
月榜
年度榜
总榜
进步榜
```

统计主口径：

```text
有效阅读词数
```

周期：

```text
周榜 = 自然周周一至周日
月榜 = 自然月
年度榜 = 自然年
总榜 = 历史累计
```

进步榜：

```text
进步值 = 本周期有效词数 - 上周期有效词数
```

进步榜规则：

```text
1. 进步榜默认按周计算。
2. 月度进步榜按自然月计算。
3. 进步值小于 100 词的学生不参与进步榜。
4. 新学生可参与进步榜，但进步值必须 ≥100 词。
5. 进步值为负不上榜。
```

展示字段：

```text
英文名 + 头像
无英文名将展示昵称
均无则展示“小朋友 + 编号”
不展示真实姓名全名
不展示手机号
```

```text
2. 未签到且活动未开始，可全额退款。
3. 未签到但活动已开始或已结束，默认不退，线下人工协商。
4. 活动开始前 2 小时关闭线上退款入口。
5. 活动开始前 2 小时内退款必须走线下人工处理。
```

活动取消：

```text
若管理员取消活动：
  所有待支付订单自动取消。
  所有待人工确认订单自动取消。
  所有已支付且未签到订单全额退款。
  已签到订单由管理员人工处理。
```

活动改期：

```text
若管理员改期活动：
  已报名学生默认保留名额。
  活动开始前可申请全额退款。
  活动开始后按原退款规则处理。
```

# 十三、最终冲突修正清单

以下 V0.2 原文规则被本文件正式修正：

| 原 V0.2 表述 | 修正后正式规则 |
|---|---|
| 待评估退会按剩余天数退观察期费 | 观察期到期进入待评估后，观察期费不再退还 |
| 音频替换不重置学生进度 | 时长差异 ≤5% 保留进度；>5% 重置全部进度 |
| Quiz 固定取前 5 题未定义排序 | 按 enabled + sort_order 升序取前 5 题 |
| Quiz 提交未定义快照 | 每次提交必须保存题目、答案、正确答案快照 |
| 预约字段含副本但未定义分配 | 预约书目，系统自动分配 available 副本 |
| 未限制已借同书再预约 | 当前已借同书目时禁止预约同书目 |
| 逾期续借人工豁免不清 | 线上禁止逾期续借；线下可人工放行，但不突破续借次数 |
| 押金状态仅未缴/已缴/退款中/已退/已扣除 | 增加 partially_deducted、fully_deducted、refunding 等状态 |
| 退会直接改状态 | 退会必须走独立退会流程状态机 |
| 人工确认订单无超时 | 人工确认订单默认 48 小时超时取消 |
| 99 元退款资格不清 | 未参加且全额退款可恢复资格；已参加不恢复 |
| 图书下架无状态 | Book 增加 active / inactive 状态 |
| 进步榜无阈值 | 进步值 ≥100 词才参与进步榜 |
| 排行榜参与范围不清 | 仅当前在册学生展示，过期/退会不展示 |
| Quiz 重置权限不清 | 第一阶段仅超级管理员可重置 Quiz 次数 |

