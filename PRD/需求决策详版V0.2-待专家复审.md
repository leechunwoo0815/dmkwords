## 术语统一（全文按此口径，避免歧义）

| 术语 | 定义 |
|---|---|
| **在册会员** | 学生会员状态 ∈ {观察期, 待评估, 正式}，即未过期、未退会的有效会员 |
| **逾期未还** | 借阅记录状态 = 逾期中（超过应还日仍未归还） |
| **同书** | 同一 ISBN 书目。同一书目的多个副本视为"同一本书"（词数/Quiz 机会/打卡均按书目维度） |
| **读完** | 音频累计有效播放覆盖 ≥ 音频时长的 95%（见决策 10） |
| **线下操作** | 馆员在场的到店操作（借/还/续借），适用全局异常原则 |
| **线上自助操作** | 家长/学生在小程序自主完成（预约/续借/Quiz），无人值守，适用硬校验 |
| **自然日/自然周/自然月** | 自然日=0点至24点；自然周=周一至周日；自然月=1日至月末 |

# 第一部分：三轮拷问拍板的 12 项（甲方明确确认）

## 决策 1：无音频书的闭环 —— 上线前提消解

**背景与问题**：Quiz 解锁依赖"音频读完"，但音频录入非必填（原稿 C3 允许后补）。若上线时存在无音频的书，这些书永远无法计入有效词数，且甲方已拒绝人工核验（原稿："不接受，全部为线上测验题"）。这是专家未识别、由架构师拷问发现的链路断点。

**决策规则**：
1. **上线前提（甲方确认）**：开馆上线前，全部在册书目（约几千本）的配套音频必须录制并上传完毕。无音频书不是常态，是上线阻塞项。
2. 上线后新书入库时，若无音频，系统**软提示**馆员"该书暂无音频，学生无法完成阅读判定与词数累计"，人工确认放行（走全局异常原则，决策 4），不硬拦截。
3. 上线后如出现无音频书被借出：学生可借、可读，但该书的"阅读进度"停留在"未读完"，Quiz 不解锁、不计词数；待音频补传后，学生继续听读完成闭环。
4. "人工录入词数"功能（绕过 Quiz 直接过账）**不做**；若未来甲方需要，作为变更需求另行评审。

**边界情形**：
- 音频上传后下架/替换：替换音频文件不重置学生的播放进度；若新书时长短于已累计进度，按新书时长重新校验 95% 判定。
- 学生听到一半音频被馆员撤下：进度保留，音频恢复后继续。

**来源**：〔拷问 1〕甲方确认"前期会把几千本书全部录制完音频并上传后项目才正式上线"。

## 决策 2：在线音频收听准入 —— 所有在册会员听全馆

**背景与问题**：原稿只确认"还书后不限制、逾期不限制"，未定义"从未借过这本书的孩子能否听"、"过期/退会会员能否听"。这决定整个音频域的权限模型。

**决策规则**：
1. **在册会员**（观察期/待评估/正式）可收听**全馆全部**在架音频，与是否借过该书、是否还书、是否逾期无关。
2. **过期会员**：不能新借/续借/预约（见决策 D3），**音频权限降级为"仅当前已借未还图书的音频可听"**。
3. **退会会员**：退会前置条件要求归还全部图书，故退会后无已借图书，**无任何音频权限**。
4. 未报名的裸注册用户（家长注册了账号但孩子未入会）：无音频权限。

**理由**：与甲方"不限制音频播放"的确认精神一致（最大化听力输入），同时保留"会员身份"与音频权限的关联（过期后收窄到已借图书），避免会员身份失去意义。

**边界情形**：
- 图书下架（馆员操作）：该书音频同步停止播放（原稿 H 组"图书下架后音频也不可播放"保留）。
- 过期会员已借未还的书，归还后：该书音频随归还即失去权限（回到"仅已借未还"口径）。

**来源**：〔拷问 2〕甲方选"所有在册会员听全馆音频"；过期降级口径为〔推导〕，请专家重点审。

## 决策 3：押金按孩子收取（每孩独立状态机）

**背景与问题**：原稿从未写明押金维度。旧项目即按孩子收。二孩家庭是 1200 还是 2400，直接影响押金状态机、退会校验、遗失赔偿扣减链路。

**决策规则**：
1. 押金 **1200 元/孩子**。二孩家庭合计 2400 元，每个孩子一条独立押金记录、独立状态机（未缴 → 已缴 → 退款中 → 已退/已扣除）。
2. 遗失/损坏赔偿：从**该孩子的**押金中扣减；该孩子押金不足扣减时，不足部分转为该孩子名下的待结清赔偿（负账），不波及兄弟姐妹的押金。
3. 退会/删除孩子档案：只校验并结算**该孩子**的押金与借阅，与账号下其他孩子无关。
4. 押金状态在馆员端学生卡片上按孩子独立展示。

**边界情形**：
- 大孩退会退押金时二孩仍在会：正常退大孩押金，二孩押金不受影响。
- 退款中（钱在途）状态下该孩子遗失一本书：遗失登记挂在待结清赔偿上（押金退款金额已在申请时冻结快照），不打断退款流程，由线下协商处理差额。

**来源**：〔拷问 3〕甲方选"按孩子收"。状态机参考旧项目 P1 模式（design-reuse/docs/billing-circulation模式手册.md）。

## 决策 4：全局异常处理原则 —— 提示不硬拦截，人工放行留痕

**背景与问题**：原稿 6 处异常场景（逾期借书、遗失未处理借书、损坏赔偿、退会拦截条件、逾期续借豁免、逾期扣分）的甲方答复高度一致："优先线下沟通协商，留住客源"。专家 P0-8 指出"人工豁免豁免的是什么"存在 A/B/C 三种理解。若不统一哲学，每条规则会各自为政。

**决策规则（全局原则，适用范围=一切线下馆员操作）**：
1. 系统对异常情况（逾期、超上限、遗失未结、损坏未赔、退会条件不满足等）**默认提示异常，不硬拦截**。
2. 馆员可选择**人工放行**当次操作；放行**必须填写原因**（必填），系统自动记录**操作人 + 时间 + 异常快照**（当时逾期几本、超额几本等）。
3. 例外——以下三类**仍然硬拦截**，不提供人工放行：
   a. **资金安全类**：支付金额校验、退款重复提交、押金重复缴纳（防重复打款/资金错账）；
   b. **数据完整性类**：同书重复借出、副本状态非法流转、Quiz 次数超限提交；
   c. **线上自助操作**：小程序预约/自助续借无人值守，前置校验（在册会员+押金已缴+额度足够）必须硬校验——线上没有馆员可以放行。
4. 豁免记录进入操作日志，支持按学生/按馆员检索（运营复盘用）。

**与专家建议的差异点**：专家 P0-8 建议"可借数量=0 时不能借"。本决策放宽为：可借=0 时馆员仍可人工放行（记录原因），与甲方"留住客源"哲学一致。请专家评估此放宽的风险。

**来源**：〔拷问 4〕甲方确认全局原则；三类硬拦截例外为〔推导〕。

## 决策 5：积分获取规则 —— 完整实现需求稿建议规则

**背景与问题**：原稿只确认了积分"不扣分、不为负、永久有效、可人工调整、不可转赠"，**获取规则从未被确认**，但第四阶段标题写着"纳入本次开发"。

**决策规则**：
1. 积分获取三通道，全部数值进 SystemConfig 可调：
   - **词数折算**：有效阅读词数每满 100 词 +1 积分（按每次 Quiz 通过入账的词数实时折算）；
   - **Quiz 加分**：Quiz 通过（≥80%）且得分 80/100 档 → +5 积分；得分 100 → +10 积分（两档互斥取高；仅首次通过该书时发放，重测更高分不补差）；
   - **连续打卡奖励**：连续打卡满 7 天 +10 积分，每满 7 天为一个周期循环发放（第 7/14/21/28…天各 +10）；连续打卡满 30 天额外一次性 +50 积分（第 30 天当次发 10+50=60）。
2. 连续打卡中断（某自然日无打卡）后，连打计数从 0 重新开始；已发积分不回收。
3. 积分账户最低为 0（无负数）；积分永久有效；积分明细对家长可见。
4. 后台支持人工调整积分（记录操作人与原因）。

**边界情形**：
- Quiz 第一次 80 分（+5 积分+词数积分），第二次 100 分：词数与 5 分不重复发，100 分的 10 分**不补发差价**（最高分仅用于通过判定与展示）。
- 词数折算的零头：累计待折算词数池，满 100 结转 1 积分，零头留存（如通过一本 450 词的书 → +4 积分，余 50 词留池）。

**来源**：〔拷问 5〕甲方选"完整做需求稿建议规则"；连打周期发放口径与零头留池为〔推导〕，请专家审。

## 决策 6：Quiz 机会 —— 终身 3 次（按书不按借阅）

**背景与问题**：甲方原话"不管借了几次，只看 quiz 是否通过，仅有 3 次机会"倾向终身制，但"每次借阅重置 3 次"也是合理解读。两者开发结果完全不同（重置制可刷）。

**决策规则**：
1. 每个学生 × 每本书目，**终身共 3 次提交机会**（与借阅次数无关，重新借阅不重置）。
2. **只有提交才计次**：未提交的退出（关小程序/切后台/断网/崩溃/页面返回）一律不占次数，答题草稿不保存，下次进入重新开始（甲方确认"只要退出了，测验就作废"）。
3. 得分取**历史最高分**作为该书最终成绩；最高分 ≥80% 即通过。
4. 3 次提交用尽且均未通过 → 该书 Quiz 状态 = failed（终态）：不计词数、无积分；学生端显示"机会已用完"。
5. **后台重置通道**：管理员/馆员可将某学生某书的剩余次数重置为 3（记录操作人+原因）；**重置次数 ≠ 人工标记通过**——甲方确认"不允许馆员人工代为标记 Quiz 通过"，任何人不能绕过答题直接置为通过。
6. 题库结构：一书可录多题（≥5），第一阶段固定取前 5 题组卷；数据结构预留"随机抽题"开关，后续打开无需改表。

**边界情形**：
- 学生 A 把书借了 3 次都没测；第 4 次借入时机会仍是最初的 3 次（不因借阅重置）。
- 管理员重置次数后学生再测：新的提交继续累计（剩余次数从 3 重新消耗）。

**来源**：〔拷问 6〕甲方选"终身 3 次"；草稿不保存、最高分、后台重置、多题预留均源自原稿甲方确认与专家 P0-9。

## 决策 7：99 元亲子活动费 —— 获客性质，每账号一次

**背景与问题**：原稿"第一次的亲子活动费用为 99 元"与"活动可独立收费（管理员可新建活动设置收费金额）"两套收费模型并存，99 元的定位不明。

**决策规则**：
1. 99 元 = **获客性质的首场亲子活动费**，目的是把新用户引导到线下（看馆、外教、藏书），促成入会。**每个家长账号终身仅收取一次**。
2. 实现为一种**订单类型**（首场亲子活动费），系统强制每账号限购 1 单；下单入口只对"账号下无任何在册/历史会员孩子"的新用户开放。
3. 后续所有活动（包括后续的亲子活动）一律走**通用活动收费模型**：管理员创建活动时可配置费用（0 元=免费活动，或任意金额），与 99 元获客单无关。
4. 99 元本身进 SystemConfig（`price_first_activity`），数值可调。

**边界情形**：
- 大孩当年入会时付过 99 元，二孩现在入会：不再收 99（账号维度一次性），二孩直接走观察期/正式会员流程。
- 用户付了 99 未参加活动即要求退款：活动未开始且未签到 → 全额退（走通用活动退款规则，见 D24）。

**来源**：〔拷问 7〕甲方对获客定位的完整说明；每账号一次、入口限制为〔推导〕，请专家审。

## 决策 8：观察期到期 —— 自动进入"待评估"态

**背景与问题**：观察期固定 1 个月，转正"由工作人员评估通过"。若到期当天馆员未及时评估，会员状态无定义（过期？延续？），状态机缺一态。

**决策规则**：
1. 观察期（1 个月）到期时，系统自动将学生状态置为 **待评估**，**不自动失效、不自动转正**。
2. 待评估期间**完整保留全部会员权益**（借阅/预约/音频/Quiz/活动/积分/排行榜）。
3. 待评估 → 正式会员：仅由馆员在后台操作"评估通过转正"，转正时学生支付年费（6000 或二孩 5400，见决策 11）。
4. 待评估 → 退会：走退会流程（观察期退会规则：还清图书后按剩余天数退观察期费 500，退押金）。
5. 待评估**无时限**：直到馆员操作为止（与"留住客源"哲学一致）。运营报表中"待评估"单独成列，提醒馆员跟进。

**边界情形**：
- 待评估状态下借的书到期未还：正常进入逾期流程（借阅状态与会员状态独立）。
- 学生处于待评估时账号下另一孩子新入会享二孩 9 折：待评估算在册会员（见术语表），**享受**（见决策 11 判断规则）。

**来源**：〔拷问 8〕甲方选"自动进入待评估"；无时限与报表单列为〔推导〕。

## 决策 9：打卡定义 —— 当天首次读完即打卡

**背景与问题**：原稿两句有歧义："有效读完一本书算打卡"（若"有效"=Quiz 通过，则与"不论测验是否通过均计时长"矛盾）vs "每天至少读完一本书就自动打卡"。

**决策规则**：
1. **打卡 = 当天（自然日）首次"读完"一本书**。"读完"= 音频累计有效播放 ≥95%（决策 10），**与 Quiz 是否通过无关**。
2. 同一本书同一天重复听完：当日打卡已达成，不重复计。
3. 同一本书不同天再次听完：不重新打卡（该书打卡终身只认首次读完那天）——防止重听刷连续打卡。
4. 连续打卡按自然日计算：每日 0-24 点内有打卡即算 1 天，中断归零重计。
5. 一天读完多本：当日打卡仍只算 1 天（连续打卡的单位是"天"不是"本"）。

**边界情形**：
- 跨零点听完（23:50 播放，00:10 达成 95%）：按**达成判定时刻**所在自然日（次日）计打卡。
- 决策 1 的无音频书：无法"读完"，不产生打卡（音频补传后首次读完才打卡）。

**来源**：〔拷问 9〕甲方选"当天首次听完音频即打卡"；同书终身一次与跨零点口径为〔推导〕。

## 决策 10：音频"读完"判定 —— 累计有效播放 95% + 原始时长记账

**背景与问题**：专家 P0-6 指出若仅监听进度条到尾，学生拖动进度条即可刷"读完"。必须精确定义。

**决策规则**：
1. **累计有效播放覆盖 ≥ 音频总时长的 95%** 判定"读完"：
   - 系统记录学生实际**播放过的时间段**（按音频时间轴的区间并集）；
   - 拖动（seek）**跳过**的部分**不计入**覆盖——直接拖到最后，覆盖仅为末尾一小段，不判定读完；
   - 断点续播：多日多次播放的覆盖区间累计合并。
2. 倍速播放：允许，档位固定 0.75/1.0/1.25/1.5/2.0；倍速下覆盖按音频时间轴计算（2 倍速播 1 分钟 = 覆盖音频 2 分钟）。
3. **阅读时长记账 = 音频原始时长**：首次判定"读完"时一次性累加该书音频原始时长（30 分钟音频用 2 倍速 15 分钟听完，阅读时长记 30 分钟）；重复听完不再累加。
4. 首次"读完"时一次性触发三件事：累加阅读时长、触发当日打卡（决策 9）、解锁该书 Quiz。
5. 播放进度（断点位置）保存在**服务端**（换手机不丢）。

**边界情形**：
- 网络卡顿导致某段重复播放：覆盖取并集，重复部分不重复计算，不会超过 100%。
- 音频文件被替换且时长变化：按新时长重新校验（决策 1 边界已覆盖）。

**来源**：〔拷问 10〕甲方选"累计 95% + 按原始时长记"；覆盖取并集、倍速覆盖口径为〔推导〕（专家建议的工程化细化）。

## 决策 11：二孩 9 折 —— 仅年费，下单时点在册即享

**背景与问题**：专家 P0-10 问题 3 指出"同一账号二孩 9 折"未定义适用订单类型、判断时机、大孩退会后是否回收。

**决策规则**：
1. **适用范围：仅正式年费**（6000 → 5400）。观察期费 500、首场亲子活动 99、活动费、押金 1200 均**不折**。
2. **判断时机：年费订单创建时**，该家长账号下存在**另一个孩子为在册会员**（观察期/待评估/正式，见术语表）→ 本单自动 9 折。
3. **不回收**：下单时享受了折扣，之后大孩退会/过期，二孩已付的 5400 与后续权益不变。
4. **泛化**：不限"二孩"，第 N 孩（N≥2）的年费订单均按此规则享 9 折（判断条件是"账号下已有任一其他在册孩子"）。
5. **不叠加**：不与其他优惠并存（当前也无其他优惠通道）。折扣率进 SystemConfig。
6. 退款：二孩年费退会按**实付 5400** × 剩余天数比例计算（决策 D-退费公式）。

**边界情形**：
- 双孩同一天先后下单年费：第一单（下单时无其他在册孩子）原价 6000；第二单（第一单支付完成、孩子在册后）享 5400。若两单都在"未支付"状态同时创建：第二单创建时第一孩尚未"在册"（未支付），判 6000；甲方如希望都享折扣需线下补差——**默认按系统时点判定，不做追补**。
- 大孩处于待评估（未转正）：算在册，二孩享折扣（决策 8 已定义待评估为在册）。

**来源**：〔拷问 11〕甲方选"仅年费+在册即享"；不追补、泛化到 N 孩为〔推导〕，请专家审。

## 决策 12：进步榜算法 —— 周期有效词数增量

**背景与问题**：专家 P1-9 指出进步榜无算法无法开发。

**决策规则**：
1. **进步榜 = 本周期有效阅读词数 − 上一周期有效阅读词数**，按增量从高到低排名。
2. 周期口径：进步榜默认为**周榜**维度（本周 vs 上周，自然周周一至周日）；月度进步榜同公式（本月 vs 上月）。
3. 增量为负（退步）的学生：仍上榜，按增量降序排在正增量之后（不隐藏，避免"退步即消失"伤害孩子）。
4. 新学生（注册时间在上一周期内）：上周期词数为其实际入账部分（可能为 0），增量 = 本周期词数，正常参与。
5. 榜单维度共五种：周榜 / 月榜 / 年度榜 / 总榜 / 进步榜（周）。**学期榜后置**（需先定义"学期"起止，甲方未定义）。
6. 主榜依据：有效阅读词数（甲方确认排行榜是"激励孩子斗志的主要方式"，主口径与核心价值一致）。

**来源**：〔拷问 12〕甲方选"周期词数增量"；负增量不隐藏、新学生口径为〔推导〕。

## D5：逾期上限扣减（回应专家 P0-8 问题 1/2）

- 人工豁免语义（回应专家"豁免 A/B/C 三种理解"）：豁免 = **放行当次操作**（理解 A 与 C 的组合）——存在逾期时系统提示异常，馆员可放行本次借书；可借上限=0 时，馆员仍可人工放行超借（记录原因+操作人+超借快照）。

## D6：Quiz 退出与题库（回应专家 P0-9）

## D9：预约借书全规则（回应专家 P0-3）

1. 副本状态扩展：`available 在馆 / reserved 预约锁定 / borrowed 借出 / maintenance 维护中 / lost 遗失`。
2. 预约单字段：家长/学生/书目/副本/预约时间/锁定截止/状态/核销时间/取消时间；状态：`locked / checked_out / expired / cancelled`。
3. 仅可预约 **available** 副本；预约成功副本 → reserved；锁定 72 小时（配置）。
4. 锁定期内：其他用户**不可预约、不可借**该副本（馆员端同样拦截——此项为硬拦截：保护先约者权益，属数据完整性类，见决策 4 例外 b）。
5. 到期未到店：系统自动释放，副本 → available，预约单 → expired（定时任务）。
6. **预约占用借阅额度**：当前借阅中 + 当前预约锁定数 ≤ 可借上限。
7. 前置硬校验（线上自助）：在册会员 + 押金已缴 + 额度足够；逾期中可否预约——按全局原则精神，线上无人工通道，**逾期中禁止预约**（硬校验）。
8. 到店借书时存在有效预约单：优先核销预约单（预约单 → checked_out），同事务生成借阅记录。
9. 同书同副本重复预约：一个学生同一书目同时只能有一个 locked 预约单。
10. 〔专家特别提示已转达甲方〕：目前几乎每书 1 副本，预约锁定 = 该书 72 小时内他人不可借。**甲方已知悉并接受**（拷问中确认预约机制本身）。

# 第三部分：详细化过程中新发现的 5 个边界（复审重点）

> 以下是本次逐条展开时，在**决策与决策的衔接处**新暴露的缝隙，已按既有哲学给出处理，**请专家重点复审**。

## N1：过期会员的线下借书权限

- **张力**：全局原则（决策 4：线下操作提示不硬拦截）vs D3（过期不能新借）vs 专家建议（过期不能借）。
- **处理**：过期后线上自助（预约/续借）硬拦截；**线下新借可人工放行**（记录原因），因为馆员在场可判断"家长正在续费路上"等真实场景。
- **风险**：放行后忘记续费 → 借出记录挂在过期会员名下。缓解：放行操作自动生成一条"待续费跟进"站内提醒给运营专员。

## N2：连打奖励的发放周期歧义

- 需求稿"连续打卡 7 天 10 积分 / 30 天 50 积分"未定义循环性。处理（决策 5）：每满 7 天循环发（7/14/21/28…），30 天额外一次性 +50。**另一解读**：7 天与 30 天是两个一次性里程碑（终身各发一次）。请专家/甲方定夺——推荐循环制（持续激励，符合"激励孩子斗志"定位）。

## N3：进步榜的新学生倾斜

- 新学生上周期词数=0，增量=本周全部词数，天然霸榜。处理（决策 12）：允许参与（新同学上榜本身是激励）。**备选**：注册满 1 个完整周期后才入进步榜。请专家审——推荐允许参与（总榜已有老学生优势，进步榜让新生有存在感，平衡良好）。

## N4：同时创建的双孩年费订单（见决策 11 边界）

- 两单同时创建时第一孩未支付未在册 → 第二单判原价。默认不追补，甲方如需"双孩同单同时折"需引入"家庭购物车"概念（复杂化，不建议）。

## N5：待评估状态的双向出口时限

- 待评估无时限（决策 8），可能出现"永久待评估"学生。处理：报表单列 + 每周生成"待评估超 7 天"名单提醒馆员。不做强制流转（留住客源）。
