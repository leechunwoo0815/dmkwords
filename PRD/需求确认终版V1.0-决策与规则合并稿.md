### R-220：观察期评估报告

```text
1. 运营专员可在后台上传观察期评估报告（图片）。
2. 支持格式：JPG/JPEG/PNG/BMP（建议运营侧统一 JPG 压缩，BMP 体积过大）。
3. 报告挂在学生档案下，家长端孩子档案页直接展示。
4. 一份报告可关联多张图片（最多 9 张）。
5. 上传为可选操作，不作为转正强制前置（转正流程独立可用）。
6. 报告上传/删除记录操作日志；删除为软删除。
7. 转正操作时可选择关联最新评估报告（转正记录与报告互链，审计可查）。
```

### R-222：收藏夹与书架（术语重定义）

```text
1. 收藏夹（想读清单）：数量不限量，想收藏多少本书都可以。
2. 书架 = 该学生"当前借阅中"的图书视图，容量 = 借阅上限（全局默认 30 本）。
3. 书架内容随借阅自动增减，无独立收藏操作。
4. 【术语更正】V0.1 及旧文档中"书架（想读清单）"的表述全部作废，
   "想读清单"一律称"收藏夹"。
5. 收藏一本书不影响借阅额度；收藏与借阅互不联动（纯标记）。
```

### R-223：阅读等级体系（A-Z）

```text
1. 等级共 26 级：A、B、C … Z。
2. 晋级条件（全局默认，进 SystemConfig）：
   该等级内新完成 100 本书的"有效阅读"（= Quiz 通过）。
3. 计数口径：
   - 与有效词数同源：Quiz 状态 = passed 的书目才计入；
   - 同一学生同一书目终身只计一次（unique(student_id, book_id)，与 R-170 唯一约束复用）；
   - 重新借阅/重测不重复计级。
4. 晋级为自动触发：第 100 本通过的瞬间升级，无需人工操作。
5. 等级只升不降（与 AR 值"只升不降"口径一致）。
6. 等级与 AR 值两套体系并行：
   - AR 值：管选书推荐（±0.5），馆员人工维护；
   - 等级：管成就荣誉（护照/里程碑展示维度之一），系统自动累计。
7. 等级展示：学生档案、阅读护照、家长端。
8. 降级/重置：无。删除孩子档案时等级数据随级联删除处理（财务保留表除外）。
```

配置项：
```text
level_up_books = 100          # 每级晋级所需有效阅读本数
```

### R-224：用户端退款申请（修正 R-183 发起方）

```text
1. 家长可在小程序端对以下四类订单发起退款申请：
   first_activity_fee / observation_fee / formal_fee / activity_fee
2. 押金（deposit）退款不可单独申请，只能通过退会流程触发（R-112）。
3. 申请必须填写退款原因。
4. 同一订单存在退款申请中（refund_pending）时，禁止重复发起。
5. 审核流：用户申请 → 超级管理员审核 → 通过后按支付方式执行
   （线上微信原路退 / 人工线下退并录凭证）。
6. 审核拒绝必须填写拒绝原因，用户可见；拒绝后可再次申请（次数不限，
   但同一时刻仅一个进行中申请）。
7. 退费金额按各订单类型既有公式计算（R-102/103/193），用户端申请时
   实时展示可退金额预览（按剩余天数公式，服务端计算）。
8. 申请退款不影响会员权益，审核通过并退款成功后会员状态才流转。
```

### R-225：孩子权益转让

```text
转让物范围：
1. 仅转让会员剩余时长（正式会员剩余天数）。
2. 押金不转：大孩押金走退会退还（校验遗失/损坏/逾期后），二孩需自行缴押金。
3. 成就数据不转：有效词数、积分、等级、打卡、阅读记录、Quiz 记录、
   生词本均留在原学生名下（排行榜不失真）。

转让条件：
1. 转出方（孩子1）：会员状态为 formal 且无进行中的退会/退款申请。
2. 受让方（孩子2）：与孩子1同属一个家长账号；会员状态为 none
   （从未入会或已退会）。
3. 转出方须通过退会前置校验（无借阅中/逾期/未处理遗失/未结赔偿）。

转让流程：
1. 家长在小程序发起转让申请（选择转出/受让孩子）。
2. 申请创建后，两个孩子进入"转让锁定"状态：
   锁定操作 = 借书、续借、预约、退款申请、退会申请、孩子档案删除
   （旧项目 assert_no_pending_transfer 模式，三条链路均校验）。
3. 后台管理员审核：
   - 通过：孩子1会员状态 → withdrawn（备注：权益转让）；
     孩子2会员状态 → formal，会员到期日 = 孩子1原到期日，
     会员开始日 = 转让确认日；生成转让记录（双方学生ID、时长、操作人）。
   - 拒绝：双方状态恢复，锁定解除，记录拒绝原因。
4. 转让记录禁止物理删除，全程操作日志。

边界：
1. 二孩受让后借书仍需缴押金（押金不随转让）。
2. 转让后孩子2再购年费：按续费规则（R-104）计算到期日叠加，
   且账号下孩子1已 withdrawn 不算在册 → 不享二孩折扣（判断时点）。
3. 观察期待评估学生不可转出（仅 formal 可转）。
```

### R-226：活动取消退款人工审核（修正 R-193）

```text
管理员取消活动时：
1. 所有待支付订单自动取消（不涉及资金）。
2. 所有待人工确认订单自动取消（未收款，运营侧核对）。
3. 所有已支付且未签到订单：批量进入 refund_pending 状态，
   由后台管理员逐单人工审核后执行退款（不自动全额退）。
4. 已签到订单：管理员人工逐单处理（线下协商）。
5. 取消活动必须填写原因，通知所有报名家长（站内+订阅消息）。
```
